## 🔧 AI 技术栈 / 趋势分析

- **Agent 基座模型开始「开源配方」而非「开源权重」**：字节 Axion 1.0（⭐70，但内容密度极高）公开的是**完整训练法**——Stage I 用 10,819 条科学 / 数学推理轨迹做自包含推理，Stage II 用 7,544 条、约 3.12 亿 token 的工具依赖轨迹（答案由程序从 NASA Exoplanet Archive、OpenAlex、UniProt、Ensembl 等库算出后再由 LLM 出题），再用**异步 GRPO** 训练；Axion 1.0-122B（HLE 59.0、FrontierScience Olympiad 87.0、FrontierScience Research 66.7）在 32 张 GPU 上两段 SFT 总共约 240 GPU 小时。README 直接写明「没有专门的 mid-training、DPO 或 on-policy 蒸馏」。**开源的不再是模型，而是「怎么把通用 Agent 训出来」的方法论**——这比放权重更进一步。
- **Skill 正在把「能力」和「载体」彻底解耦**：gif-factory（1,344⭐）把 GIF 制作拆成七个可独立安装的 Skill，kubai-icons 是「一套 skill + 2,800+ 图标库」，MiniMax-H3-Image 直接用 `npx skills add` 挂载 `h3-image-prompt-writing` 技能、渲染走自家 API（国内 `MINIMAX_API_BASE=https://api.minimax.cn`），fujiang-pojia 则是 DeepSeek Harness 的破甲插件（激活词「富江」，版本 0.20.13，含技能库调用、漏洞知识库 PoC 与报告更新）。**Skill 已经是跨厂商的最小分发单位**——不绑模型、不绑宿主、只绑 SKILL.md。
- **「给 LLM 用的工具」形成独立设计范式**：sand3d 把整个 API 压进约 3,600 token、单个零件 token 比 Blender Python / CadQuery / FeatureScript 少 2–6 倍、用「命名寻址」替代手算坐标；vork 用 Rust + Slang 写无头 GPU 渲染引擎、核心 API 约 2,500 token、**故意不做可驱动的编辑器**。两者指向同一判断：**能被 Agent 完整吃下的 API，必须先为 token 预算设计，而不是为人设计**。
- **推理成本已经不是 Agent 落地的瓶颈，端到端交付才是**：agent-autoloop 的价值不在模型而在「等审批时不占进程、不烧 Token」；expo/exact 把「干净 clone 上 57 分钟跑完四个平台」当成产品指标；pinky 把审批放在网关而不是提示词里；sandbox-mcp 给 Agent 一台真实一次性 Windows 11（GUI 采样端到端约 40–50 秒）。**Agent 工程的主战场已从「调 API」转向「管交付」**。
- **监管与地缘风险第一次直接进入 AI 基础设施的定价**：英伟达董事会连夜开会评估是否罢免黄仁勋（盘后跌约 8%、五个交易日累跌约 11%），美国众议院中国委员会准备传唤，国会将以「涉嫌中国间谍」名义启动程序；而同一天 CoreWeave 转向客户预付款 + 短合同融资来支撑 1,325 亿美元订单积压。**算力供给方的人事稳定性，已经和芯片产能一样成为 AI 产业链的一级风险因子**。

- **「开源什么」正在成为比「模型多强」更重要的竞争维度** —— 字节 Axion 1.0 开的是**训练法**（两段 SFT + 异步 GRPO、10,819 + 7,544 条轨迹、约 3.12 亿 token、32 卡 240 GPU 小时），百度文心 5.5 Flash Preview 开的是**权重**（2,800 亿总参 / 140 亿激活、百万 Token 上下文、宣布即开源），MiniMax-H3-Image 开的是**技能 + 权重**（16 MP 原生出图 + `h3-image-prompt-writing` skill）。三条路线同时指向一个判断：**模型能力正在迅速商品化，稀缺的变成了「配方」和「接入方式」——谁定义 Agent 怎么被组装，谁就定义下一轮的生态位**。
