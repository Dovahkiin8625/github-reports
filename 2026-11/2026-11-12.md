## 🔧 AI 技术栈 / 趋势分析

- **「从 0 造系统」正在成为模型能力的验收单位**：Anthropic 用 1000 个 Fable 5.2 Agent 从空文件夹昼夜连轴转 8 天，写出带内核、磁盘与网卡驱动、文件系统、窗口界面甚至安装程序的完整操作系统，在笔记本上直接跑通开机；同批 Agent 30 小时完成费马大定理的形式化证明（动作 token 只有上一版 1/3、证明代码缩短 7 倍），而同样拉起 1000 个 Agent 的 Opus 5.5 跑满 18 小时卡在 26%、30 小时也只到 27%；再用一段话提示词 24 小时内设计出三款电子设备——自己写规格书、从分销商库选现货元器件、完成四层 PCB 布线、CAD 建模 3D 打印外壳、写底层固件——三块板全部达到投产标准、零电气修改。GitHub 侧的 expo/exact、dsh-game-studio 则把「写完立刻跑起来」直接当成交付物。
- **Agent 的执行层正在拆成三类可复用基础设施**：受控整机（sandbox-mcp 给 Agent 一台真实一次性 Windows 11）、跨本体技能迁移（英伟达 GR00T 2 的 X-Adapt，人类动捕示范 20 次试验成功率 65%，手持 UMI 夹爪迁移到 YAM 机械臂成功率 60%，Dexter-50 上零样本 40% → 1 次示范 71% → 5 次示范 95%）、跨硬件感知统一（蚂蚁灵波 LingBot-Touch 把磁触觉 / 视触觉 / 压阻式信号编码成同一套触觉 Token，T-Rex 拧瓶盖成功率 56.25% → 90%）。大晓机器人的 Mundo + Astra 双脑架构是同一逻辑的商业版：云端大脑 Astra 探索出的方法固化成 Skill 交给端侧小脑执行，同一轮洗衣房流程从 30 多分钟降到 18.648 秒，耗时缩减超 98%。
- **Skill 与 MCP 成为新的分发层**：Adobe 在 MAX 大会上发布 MCP server，让 ChatGPT / Claude / Gemini 直接调用 Photoshop、Premiere、Firefly 的能力，同时把 Firefly 的 Agent 改成 proactive、always-on 以获取更多上下文；GitHub 上 kubai-icons 是「一套 skill + 2,800+ 图标库」，download-anything 是 CLI 与 Skill 双入口（自动剥离分享口令、落盘字幕 / 封面 / 独立音轨 / BibTeX 引用），auto-ontology-mcp 把 NVIDIA Auto Ontology 的语义层接到任意 MCP 客户端做 text-to-SQL。**分发权正在从模型厂商手里转移到 skill 作者手里**。
- **记忆层与可观测层独立成栈**：Brain4Agent 用字符二元组做 CJK 优先 BM25（无需分词模型、无需 API key、单次查询毫秒级，装 jieba 精修版 hit@1 达 0.950），并坚持「只报证据不报结论」——检索结果会明确告诉你语料里从未出现过哪些词、某个会话缺哪些词；lot-map 把 Claude Code 的每一次 tool call、模型步、hook 和 skill 画成聊天窗旁边的一张活地图（记忆 / 文件 / shell / web / agent 各自有工位）；agent-autoloop 则把命令行 Agent 做成事件驱动 + 插件化的后台中台。**Agent 工程正在分化出与模型无关的独立层**。
- **算力供给侧今天给出三个硬数字**：CoreWeave CEO 称 2027 年剩余可用产能的订单认购倍数已达 10 倍、2028 年规划产能高出数倍（当日股价暴涨 20%）；英伟达与矽品精密确认扩大 CPO 光引擎产能，目标 2027 年年中提升至目前的 15 倍、2028 年底再翻一倍；国产侧阿里已向港交所提交分拆平头哥独立上市申请，其真武系列 AI 芯片截至 2026 年 4 月累计出货 56 万片、IDC 口径 2025 年中国云端 AI 加速器出货量第二（26.5 万片，仅次于华为 81.2 万片）。需求、产能、资本三条线同时收紧。
