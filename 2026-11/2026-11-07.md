## 🔧 AI 技术栈 / 趋势分析

- **「Agent 需要一台专属机器」成为共识**：DeepSeek 的 dsh-superagent 是"单个仓库一个主动 Agent"，Mika 把 Android 屏幕虚拟化成执行层，DSH-Android 免 ROOT 直接在手机上跑 Harness，terminal-mac 用虚拟机给 computer-use Agent 造受控桌面，量子位同日发《为什么每个 Personal Agent 背后，都必须配备一台"云电脑"？》——执行层正在从各家私有实现，收敛成一层独立的公共基础设施（Meta Muse Secure VM / Manus 每任务一台云 VM / OpenAI dots 一台云端电脑 + 虚拟浏览器）。
- **Agent Skills 化到"专业垂直化"阶段**：Top 10 里 3 个是 Skill（claude-animated-shorts 动画短剧、stack-diagram 架构图、agent-autoloop 自动化中台），补充池里还有 reanimate（逆向动画）、floorplan（代码库交互式地图）、grim-prompter（36 个架构工作流做威胁建模）、patch-gg/pixelfx（244 个像素特效 + 生成 skill）。SKILL.md 已经不只是提示词集合，而是**可交易的专业工种说明书**。
- **端侧 / 屏幕理解双线推进**：Mika（端侧 Android Agent）、fish-pocket（iPhone 上跑 DeepSeek Harness）、dsh-see-now（按变化量筛帧、多帧拼图，静止画面几乎不花 token）、govijr/terminal-mac（虚拟桌面）——Agent 打通"看见屏幕"和"动手操作"两端，中间靠虚拟化隔一层。
- **国产芯片押注稀疏化，与模型架构互为因果**：DeepSeek-V4-Pro 总参 1.6 万亿但每 token 只激活约 490 亿（约 3%），墨芯据此做"权重稀疏 + 激活稀疏"双稀疏专用推理芯片，5 个月连融两轮近 10 亿元，MLPerf Inference S30 连续三届夺冠；同期百度文心 5.5 Flash Base（2800 亿总参 / 每 token 激活 140 亿）用 Latent-Gated Sparse Attention + Multi-Router Latent MoE + ECHO 把稀疏做进模型本身——**算力节省正在同时发生在模型层和硅层**。
- **AI 支出增长第一次出现"用量涨、账单不涨"**：Ramp 数据 8–9 月 token 支出环比仅增 1.5%，而 7 月是 42%；腾讯 Hy4 单任务成本 0.78 美元，比 Grok 4.7 便宜 10 倍、比 Qwen 3.8 Max 便宜 13 倍。降价正在吃掉规模的增量，**"AI 超增长"作为投资假设第一次被真实账单数据挑战**。
