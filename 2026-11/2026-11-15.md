## 🔧 AI 技术栈 / 趋势分析

- **Agent 拿到的「手」正在从函数调用升级为「拥有整机」**：pinky（Go）和 poki（Swift）分别用 MCP 接管真机手机，sandbox-mcp 更进一步——直接给 Agent 一台**一次性真实 Windows 11 机器**（不是假装成 Windows 的容器），启动、部署、驱动 UI、捕获崩溃、保留证据、然后销毁，GUI 采样端到端 40–50 秒；vork 给 Agent 一个约 2,500 token API 的 GPU 渲染器；gpucanvas 用 WebGPU 一次 instanced pass 画出 5,000 个活 DOM 节点并让 Agent 读到一棵 JSON 树。**共同点：接口粒度正在从「一个函数」变成「一个可被支配的环境」**，而这类项目全部把「审批 / 记录 / 销毁」做进宿主，而不是靠提示词约束。
- **Skill 已经不是提示词模板，而是承载工程经验和失败模式的知识包**：ste80-humanizer 把 Wikipedia《Signs of AI writing》的 26 条 AI 腔调清单与 Karpathy 的 STE80（航空维修手册式受控英语）合成两遍处理；turkish-anti-ai-skill 指出土耳其语的问题不在词汇而在**句法骨架**（形容词后置、机械的 ve 连接、句尾一律 -DIr/-mAktAdIr、18–22 词的单调句长带），并按 TDK 书写指南重建；guizang-game-skill 则直接把作者用 Fable 5.2 花 6 小时、约 4.5 亿 Token 做出《雾锁山门》的**踩坑过程**写成流程，产出是一个 33 MB 的单文件 HTML 武侠 3D 动作游戏。**「Skill = 可安装的经验包」这一形态，已经开始吃掉原来属于教程和 prompt 库的生态位。**
- **「本地优先」从隐私口号变成了可分发的产品形态**：yogurt 用 whisper.cpp 在本机做 99 语言转写并配本地 MCP server；chat-demo 是纯静态站点、浏览器直连 API、无后端、密钥只存 localStorage。**当端侧模型能力和静态分发同时成熟，「上传到云端才算 AI 产品」这条默认路径正在失效**——这也是当日舆论的另一面（见 AI 新闻第 5、6 条）。
- **世界模型与多机协同指向同一个省算力结论**：supermimic 用一个可微分世界模型直接训练人形全身追踪；星尘智能 CoMind 让两台机器人隔墙「借眼」完成拿笔（成功率 0%→100%），盲盒置物在**信息传输量减少约 80%** 的前提下准确率从 38.9%（不共享）提升到 88.9%，靠的是**动作级反向传播**——队友动作出错会反向修正信息编码器的特征提取。两条独立路径说明同一个方向：**下一阶段的瓶颈不是算力，而是「让模型用更少的带宽做更准的判断」。**
- **算力的计价单位正在从「GPU·小时」迁移到「Token」，而新指标尚未被市场接受**：联想在河北张家口落地「万全混合词元工厂」，首期 15000P 异构算力集群 + 约 100MW 智算中心，**Token 年产 2000 万亿、峰值每秒 2 亿**，2027 年建成、2030 年计划再扩 10 倍；同期周小川在资本市场学术年会上直言「流量、Token 等新估值指标尚存争议」，但也确认 AI 投资已集中于算力大模型、场景应用、底层配套三大方向。**供给侧在用 Token 当标尺，需求侧还没学会用它定价——这个缺口就是未来两年 AI 基建泡沫与繁荣的分界线。**
