## 🔧 AI 技术栈 / 趋势分析

- **Agent 架构的竞争焦点从「单次回答质量」转向「主动发现 + 持续在线」**：DeepSeek 开源的 Super-agent 把四个特征写死——连续（跨会话跨平台保持上下文）、高效（多任务并行）、主动（持续观察环境变化、必要时自行行动）、持久（长期在线、异常自恢复）。工程上最狠的是把 Router（收消息、派任务、维护全局上下文）与 Worker（具体执行、互不干扰）分层，加「订阅与直通」机制（Worker 直接订阅它接手的 PR 后续评论，不再经 Router 层层转发）、投机执行（群里聊到 Bug 就先去复现，找到简单修复才交人）、两级事件过滤（先用程序规则筛掉噪音，再用大模型判断要不要动手，省 token）、异步 ReAct Loop（耗时任务不阻塞新指令）、以及一个专门监督其他 Agent 的 Watchdog。实测：模拟约 300 条消息、20 项工作请求的协作环境，每种配置跑 5 次，Super-agent 任务完成时间中位数 12.4 分钟、95 分位 15.7 分钟，优于传统单 Session + Subagent 方案。核心判断是：模型变强之后，多任务效率的瓶颈不再是模型，而是**人类的注意力带宽**（DeepSeek 观察到一个人通常只能同时跟进 3~5 个活跃 Session）。

- **Skill 已经同时长出「生产力」和「防御力」两面**：ub-mode 把软件工程纪律、unslop 把前端审美、pixelfx 把像素画工艺打包成可安装的 SKILL.md，对面 BLA 就把 AI 逆向工程变成不划算的生意——Poison → Exhaust → Hallucinate 三段式让逆向 Agent 的分析器撞资源预算、追进诱饵、白烧 token，而运行时行为不变。这是同一天、同一件事的两面：一旦 skill 成为可分发的软件包，它就同时有了 npm 生态的攻击面和价值，企业的正确应对不是发通知，而是把 skill 扫描写进 CI 并对「安装即执行」做审计。

- **端侧 Agent 的三件套已经齐了，而且工程细节开始收敛**：dsh-Go 内置 Linux 免 Root 免 Termux 在手机上跑 harness 并能遥控电脑，Mika 在一块看不见的后台屏上操作 App 和网页（不占你的屏、什么 App 都不用适配、页面一碰就停），digital-human-koubo 一张照片一句话产出 27 秒成品口播（总成本 482 个 Renoise 积分）。三者共同的收敛点是「最后一公里」：安装路径可被另一个 Agent 自动执行、密钥不经过中间人、涉及付款和验证码的动作一律交还用户。

- **开源小模型 + 多 agent 协作，已经能正面啃下闭源旗舰的硬骨头**：HN 上一篇复现（66 分）用五个 Qwen3.8-27B（planner、两个 ideator、solver、manager 各起一个全新上下文，只通过磁盘文件通信）跑 LiveCodeBench Hard 前十题、五遍全过，每一遍程序都在公开和隐藏测试上跑分——平均 5.0，对比同一团队自己写的单 agent harness 的 9.6，以及 Fable 5 单打独斗的 8.0。关键不在模型大小，在于「角色分工 + 文件通信 + shell 脚本判胜负而非模型自评」这套编排方式。

- **AI 基建的融资门槛正在抬高，而且开始需要芯片厂签字**：英伟达在谈为 Nscale 西弗吉尼亚的 Anthropic 数据中心做数十亿债务的「剩余价值担保」（Nscale 违约时英伟达接管设施、帮找买家和新租户），该项目仅第一栋楼的 Anthropic 合同就达 446 亿美元、460MW，将用下一代 Vera Rubin 芯片。另一边 Runware 想把数据中心做成流水线产品——罗马尼亚工厂计划 2028 年达到每天 30MW、接近每月 1GW 的产能，「一年产量相当于全美今年新增的数据中心电力容量」。而需求端则在收缩：OpenAI 把新一轮融资目标从 300 亿美元、1.4 万亿估值下调到 200 亿美元（1.25 万亿估值），已锁定 110 亿，WSJ 称部分大额投资者反应"冷淡"，领投方来自阿联酋。三件事指向同一件事：AI 基建的钱越来越难从资本市场直接拿，得靠产业方互相担保。

## 🎯 AI 重点关注

- **Agent 的下一个战场是「主动」而不是「更强」**：DeepSeek 的 Super-agent 把架构目标定成「群里没人 @，AI 自己找到 Bug 并提交 PR」，并用 Router/Worker 分层、订阅直通、投机执行、Watchdog 一整套机制支撑这件事；对应的 dsh-superagent-prototype 仓库一天 2,593 星。这件事的行业含义是：**下一批 Agent 产品的差异化不在回答质量，而在「不需要你开口」的触发能力和 24 小时不掉线的可靠性**。而今天同时上榜的 dsh-Go、Mika、digital-human-koubo 说明端侧执行层也在同步成熟——触发逻辑在云、动作在手机，正在成为标准形态。

- **AI 基建的钱变贵了，而且开始需要产业方互相担保**：英伟达谈为 Nscale 数十亿债务做剩余价值担保（对应 Anthropic 446 亿美元的首栋合同）、OpenAI 把融资目标从 300 亿下调到 200 亿且只落实 110 亿、Runware 想用流水线工厂把数据中心做成"年产量等于全美今年新增电力容量"的工业品。这三件事的方向一致：AI 基建从"资本开支故事"进入了"项目融资故事"，而**芯片厂替客户担保是最能说明问题的信号**——它意味着风险已经从财务报表传导到了产业链上下游。对创业公司的含义很直接：算力合同签得越大，资产负债表风险越大。

- **开源小模型正在从「能力对标」转向「编排对标」**：五个 Qwen3.8-27B 各起独立上下文、只靠磁盘文件通信、由 shell 脚本而非模型判胜负，在 LiveCodeBench Hard 上五遍全过、平均 5.0，赢过 Fable 5 单模型的 8.0。这条路的杠杆不在参数规模，而在上下文隔离 + 可验证的外部评分器 + 角色分工三件套——全是模型无关的工程。同一天 Anthropic 给 200 美元档取消 5 小时窗口限制、OpenAI 给 Pro 额度翻倍，则是另一半证据：前沿模型的推理成本已经高到必须靠套餐分层来疏导，而编排能力正是当下唯一能压住这笔账的杠杆。
