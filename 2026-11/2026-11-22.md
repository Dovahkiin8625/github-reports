## 🔧 AI 技术栈 / 趋势分析

- **「决策模型」从概念变成了可下载的组件，这是今天最硬的技术栈变化**：Karpo Decision 31B 开源后，**System 1 / System 2 拆分已经从论文走向可安装的中间件**——`karpo-decision` 提供 31B/12B/9B/4B/2B/0.8B 全系列（骨干分别是 Gemma 4 与 Qwen3.5，输出是「选项 → 概率」的读数而不是逐字生成），`karpo-browser` 提供整套浏览器 Agent 架构（MCP server + 运行循环，**System 1 每步只从页面自身给出的编号选项里挑一个动作，System 2 只负责规划、阅读与作答**），并附带网页动作决策评测集 KBB。背景是决策模型赛道在 24 天里被炒热——Jev 背后的 TypeSafe AI 拿到 75 亿美元估值，OpenAI、微软、亚马逊、Cloudflare 纷纷进场。**判断：这条线的经济学意义比它的技术含量更大——Agent 每一次「选工具、筛结果」都调一次通用大模型，等于每次都付「写小作文」的价钱；把这一步从模型里剥出来，是 2026 下半年 Agent 成本结构最直接的一次下修。**
- **「可验证」今天长出了三种形态，而且今天第一次出现了对照组**：**形式化级**（Lean 与 Mathlib 社区联合声明认证 Alpöge 的 1,700 万行黎曼猜想证明，AXA 四条准则全满足；Sutherland 用 Claude Code 驱动两个独立内核 nanoda / con-leche 复核并接受完整导出证明）、**流程级**（Grok Bot 首席工程师 Lauren Tan 的「信任倒金字塔」——代码与架构在最上层，Lint 规则、类型系统、编译器与自动化测试在第二层，运行时验证与自然语言规则在第三层，**她明确说「最值得投入精力的是最上面两层」，并把 Cursor 时代 Agent 给定时器打补丁的教训总结成「直接禁掉 99% 的代码注释」**，其团队单月交付 1.1 万个 PR、撤回率 0.5%）、**因果级**（SimpleBench 把基准从「模型会不会」换成「人类会不会」——**人类 83.7% vs Claude Fable 81.9%**，200+ 道题覆盖时空推理、社会智力与语言对抗鲁棒性）。**判断：评价 AI 产物的方式正在从「模型说了什么」转向「产物能不能被另一套系统判过」——而今天同周出现的「Masullo 人类 GRH 草稿 8 小时后被 AI 辅助找出问题」正好是反面刻度：没有证书的，连 AI 都能挑出漏洞。**
- **Rust 重写这条线出现了明确的路线分叉：「整包重写」正在让位于「只改慢的那 5%」**：rust-anything 的路子是全量重写但每步都要过 `diff → gate`；同期出现的 **fast-anything** 明确反着来——**「不要用 Rust 重写它，把慢的那 5% 重写掉」**：它先 profile 出真正吃时间的少数函数，让 Agent 只移植这些函数，**用真实录制的调用证明移植前后结果一致**，再换进去，一条命令、可回滚。README 给的理由非常具体：**整包重写要花几个月、编译动辄几分钟、还要背几个 GB 的 `target/` 目录，而运行时绝大部分时间其实就落在几个函数里**。**判断：这是「可验证重写」从炫技走向成本工程的第一步——对绝大多数企业代码库而言，先做性能剖面再决定移植范围，才是能被预算审批的方案。**
- **本地推理已经从「爱好者项目」变成了一条正经的产品定位**：Linger 用 PolyStrata 把 125B MoE 塞进 12GB 显存（GPU／内存／SSD 三级分层热管理），inference-optimisation-skill 让 Agent 先算物理天花板再动手爬山（Intel Arc B390 上 256K prefill 提速 2.1×、KV 扩到 4×256K），neonclipping 干脆「Fast 模式从不看完整视频」，**agy-fast** 则把「减少 Agent 墙钟延迟、可计费 token 配额与工具调用次数」直接写成插件卖点（零运行时依赖，同时兼容 Google Antigravity 的 CLI `agy`、Desktop 2.0 与 IDE）。**判断：这一组仓库共同说明一件事——「本地跑」已经不需要再论证可行性了，现在要论证的是「在什么硬件上、快多少、贵多少」，这是成本表而不是信仰问题。**
- **Agent 记忆的真实瓶颈终于被量出来了，而且不是「检索」**：腾讯元宝 × 伦敦国王学院 NLP 团队的 **GroupAssistBench** 用 **50 个真实群聊、80,299 条历史消息**构建 **2,395 道题**（L1 记忆召回 1,374 道 + L2 开放式服务 1,021 道），比较了完整上下文、检索增强与外部记忆等 **14 组配置**。最有信息量的两个数字：其一，**EverMemOS 的 L1 召回分 0.621 高于完整上下文的 0.570，但 L2 服务分只有 0.247，反而低于完整上下文的 0.431**——**「更会回忆，并不必然更会服务」**；其二，团队追踪了 **497 条配对记忆**（同一段历史既被 L1 直接问、又被某项 L2 服务依赖），结果是 **L1 已召回但 L2 未被判定有效使用的记忆里，约 36% 根本没进 L2 模型输入，其余约 64% 进了输入却没在回答里被有效应用**。**判断：Agent 记忆的下一个战场不是「存更多」而是「归因与约束」——用户说「帮大家安排一下」时并没有给出检索线索，模型必须先判断此刻该用谁的哪条记忆，这是一条被长期忽略的推理工作。**
- **GitHub 榜单本身的信噪比今天掉到新低**：今日候选池 **174 个唯一仓库里有 55 个（31.6%）属于 3 个克隆农场家族**——`Gemini-Config-Checker-` 21 个（描述一字不差「Chain region scanner…」、topics 完全相同、创建时间集中在 11-15 16:46）、`GitHub-Copilot-app` 17 个、`ai--manus2.0` 14 个（11-13 与 11-14 两批）。**识别这类仓库的正确做法是按 `tuple(sorted(topics))` + 描述前缀分组，而不是按仓库名归组**——否则名字前缀不同的同族会被漏掉。**写日报的功课就是把「家族」数出来，而不是把「仓库」数出来。**

- **AI 科研的瓶颈已经不在「能不能证出来」，而在「谁来担保它是对的」——而担保方式正在从同行评议转向机器验证**：本周出现了完整的一组对照链。**正面的一侧**：Lean 与 Mathlib 社区联合声明认证 Alpöge 的黎曼猜想证明（1,700 万行 Lean 代码，只依赖 Mathlib，Xena 四条准则全满足），MIT 的 Sutherland 用两个独立内核 nanoda 与 con-leche 复核并接受完整导出证明，**复核流程本身由 Claude Code 驱动**；**反面的一侧**：Masullo 的纯人类 GRH 证明草稿以「加急公告」形式放出后（HN 2,393 分），**八小时内多人报告用不同 AI 模型辅助找出了问题**，作者随即更新说明「所有问题都需在社区满意解决后才会被接受为真」。**判断：这两件事合起来定义了 2027 年 AI 研究的准入门槛——「AI 提出了多少新结果」会迅速贬值，「有多少结果能被机器独立复核」会升值。** 对做 AI 科研工具的人有三条具体方向：其一，**投资应该压在「可读性与可复述性」上，而不是更强的搜索**——陶哲轩式的「答案无法直接从产物里读出来」是当前真正的瓶颈；其二，**形式化中间件（Lean、ASL、GDS）会从数学专用扩散到其他所有可验证领域**——Architect Labs 为 AI 设计的规范语言直接翻译到 Lean 4 就是这个信号；其三，**「用 AI 找出 AI 产物的错误」正在成为一个独立工种**——Masullo 案例里的关键角色是「用不同 AI 模型辅助发现问题的数学家」，**这个角色会在明年大量出现在论文脚注里**。

- **决策模型是 2026 下半年最被低估的一层，它的意义在成本结构而不在模型质量**：Karpo Decision 31B 开源并以 Decision Index 总榜 73.9 分登顶（300 个模型同台、单次前向推理输出整组选项概率、单卡 RTX PRO 6000 上线、14 万次请求中位 94ms）；配套浏览器框架在 Browserbase Benchmark v2 的 102 道任务上做到 **89% 成功率 / 201 秒 / 单任务 0.096 美元**，比 Claude Fable 5.2 + Claude Code **快 1.9 倍、成本 1/13**；背景是 Jev 背后的 TypeSafe AI **24 天 75 亿美元估值**。**判断：Agent 时代真正的成本大头不是「模型多聪明」，而是「每一步都要让通用大模型生成一句话」这个架构假设。** 拆掉这个假设会带来三个连锁反应：**其一，Token 计费压力从「上下文长度」转移到「决策次数」，因而「让模型少做决定」比「让模型少读上下文」更值钱**；**其二，决策模型会像 embedding 一样迅速分层**——通用层被大厂占据，垂直层（浏览器、客服、工单、交易）被开源方案吃下；**其三，也是最关键的，评测集就是这一层的护城河**——KBB 这类网页动作决策基准的定义权，等于对「什么叫决策做对了」的话语权，**谁定义了基准，谁就定义了下一轮 Agent 采购清单**。同日 SimpleBench 的人类基线 83.7% vs Claude Fable 81.9% 是这条线的另一面证据：**模型的推理并没有全面超过普通人，它只是更擅长那些可以用「选项打分」形式化的判断——而这恰恰是决策模型的主场。**

- **AI 交易的第一轮公开市场定价已经结束，接下来定价的是「现金流口径」而不是「估值倍数」**：Anthropic 上市次日回落 **8.5% 至 88.91 美元**（发行价 83、首日收 97.17），**承销商全额行使超额配售后本次 IPO 发行总额约 935 亿美元、另完成约 260 亿美元私募**（微软、英伟达、谷歌等参与）；同日纳指 **-5.28% 抹平年内全部涨幅**、标普 **-3.70%**、道指 **-1.93%**（双双较近期收盘高点回落超 10% 进入回调区间）、**费城半导体指数 -10.73%**、**英伟达连续第七个交易日收低、单日约 -14%、本周累计约 -23%**，全周纳指 -10.02%、标普 -8.61%，均为 2025 年 4 月以来最大单周跌幅，VIX 盘中突破 40；**直接诱因是 SEC 执法人员正在审查英伟达潜在的会计问题**（报道未说明具体事项与调查启动时间，调查本身不代表公司存在不当行为）。**判断：本轮 AI 叙事被否掉的不是「估值太贵」，而是「收入什么时候被确认、钱有没有收到」——Anthropic 上市把 AI 资本结构从私人市场推到了公开市场，而公开市场每天都要给循环融资定价。** 接下来 12 个月最该盯的三个指标：**一、英伟达 10-Q 里关于收入确认口径与 SEC 调查进展的披露**（本周已推迟 10-Q，并披露董事会独立委员会在调查）；**二、Anthropic 下一份 10-Q 的算力承诺与资本开支口径**（对照已披露的 1.05–1.08 万亿美元基础设施承诺）；**三、云厂商「AI 收入增速 vs 折旧摊销增速」的剪刀差**——**第三个才是整条叙事最诚实的体温计**，因为它不依赖任何人对「泡沫」的定义。
