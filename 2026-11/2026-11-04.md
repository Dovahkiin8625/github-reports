## 🔧 AI 技术栈 / 趋势分析

- **Agent Skills 完成了第二次分工：从「通用能力」细化到「可度量、可审计」**。昨天上榜的 unslop / pixelfx / floorplan 覆盖设计、动画、架构；今天补齐的 reanimate（动效逆向，带逐帧数值比对）、code-review-skill（四个独立探针、证据支撑的门禁）、teardown（把机器拆成可交互 3D 模拟器）都在解决同一个问题——**如何让 Agent 的产出可验证**。reanimate 的动机写得很直白：Agent「做一遍就宣布完成，因为它既看不见运动过程也说不清差多少」。这批仓库的共同技术选型是 Playwright 录像 + 数值 diff + 分级探针，实质是给 Agent 配了一套回归测试。
- **「Agent harness」正在被当成独立品类做，且头部厂商亲自下场开源**。MiniMax-AI/mcode-stack（516⭐）直接把 MiniMax Code 团队自己每天用的 workflows 和 skills 开源出来——明确写着「这不是提示词合集或最佳实践清单，而是团队每天真正在用的东西」：怎么让 AI 写的代码保持高标准、任务该不该派给 subagent、长命令该等多久、长会话怎么防止变钝、每一轮该往 context 里放什么。加上 uncut（7 MB 单文件、headless、明确承诺无静默上下文截断）和 DeepSeek 官方 dsh，harness 这一层同时出现了「大厂自曝内部作业流」和「极简第三方实现」两种形态。竞争焦点已经从「谁的能力更强」变成「谁的 harness 不偷工减料」。

## 🎯 AI 重点关注

- **电力约束已从成本项升级为交付项，且开始改写产业链** —— 微软因供电排期到 2030 年代中期退出 Nscale 锚定客户资格、xAI 用 8 台改装客机发动机给 Colossus 2 供电、高盛把未来五年数据中心资本开支上调至 8.5 万亿美元，这三条同日出现。判断很直接：**2027 年之前，AI 算力扩张的瓶颈不在芯片供应，而在「多久能通电」**。受益的不再只是 GPU 厂，而是燃气轮机、电网设备、液冷、乃至航空发动机改装这类「AI 叙事之外」的配套环节；反过来说，任何以「明年上电」为前提的产能规划都应该重算。
- **Agent 生态已经分化出「能力层」和「验收层」，后者才是当前瓶颈** —— reanimate 用录像 + 数值 diff 逼 Agent 把动效做对，code-review-skill 用四个独立探针和门禁做可审计评审，teardown 把任意机器拆成可交互 3D 模拟器，sapper-v2 让 AI 军团 8 小时无人值守打满攻防赛。共同点是都承认「Agent 干一遍就宣布完成」是当前最大的浪费。与之对照，MiniMax 直接开源了自己团队每天在用的 harness（mcode-stack），uncut 用 7 MB 单文件承诺「无静默上下文截断」。**未来半年 Agent 生态的竞争焦点会从「谁更能干」转到「谁能证明干对了」**，而验收层的工具链比能力层更缺、也更容易形成独立产品。
- **成本压力第一次同时出现在三个层面，且都指向同一件事** —— Anthropic 算力成本占营收从 48% 升到 58%（招股书）；推理层看似风光但毛利被算力折旧吃掉（Fal 160 亿估值 + 8 亿年化收入）；模型层则靠「廉价模型写代码、贵模型做判断」（cheap-ag 主打省 63% Opus token）压成本。叠加美国中期选举带来的 AI 板块抛售风险（高盛预测民主党横扫两院可能引发 AI 股票抛售），**AI 的成本问题已经从单点优化变成了全行业必须回答的定价问题**：当硬件端电力吃紧、软件端推理不赚钱、模型端要自己分档降本时，唯一还能挤出利润的位置，是应用层对交付质量的确定性。
