## 🔧 AI 技术栈 / 趋势分析

- **Agent Skills 正在成为新的分发单元**：Top 10 里 solo-to-team-skills（中文协作技能包）、lot-map（Claude Code 插件）、chat-demo（官方静态 Demo）都在同一个逻辑上——把能力封装成可安装、可按名调用的产物，而不是让人去读文档。同一周里 article2media（把文章/视频一键做成小红书图文、公众号排版、口播短视频的 10 个 skill）、MiniMax 的 `h3-image-prompt-writing` 也走同一条路。**SKILL.md 正在变成 Agent 时代的「微应用商店」**，而厂商也开始把自家 API 直接包装成 skill 下发（`npx skills add` 一行安装）。
- **端侧推理进入「最小可用硬件」阶段**：smolmaxxing 在 1 GB 可用内存的 iPad Air 上跑 1-bit 1.7B、1.9 GB 的电视盒子上跑 16B MoE；配套的是 MACaQ 这类量化基础设施——用 32.5 GB 设备内存 64 分钟量化 122B 模型，困惑度低于 MR-GPTQ / DuQuant++。**「量化 + 自定义内核 + 流式加载权重」三件套叠加后，端侧能跑的上限被系统性抬高**，本地 Agent 的算力门槛从「工作站」降到了「旧手机」。
- **Agent 的执行权正在从「文本」迁移到「物理与钱」**：pinky 用 MCP 让 Agent 操作真机手机且审批下沉到网关；agentes-chat 让 Agent 成为工作区成员并按 Agent 记账预算；OpenAI 直接解散机器人团队改由 GPT-6 Astra 通吃；ChatGPT Wallet 让 Agent 代用户下单结算。**共同的架构信号是「审批必须由宿主强制执行，不能靠提示词约束 Agent」**——这正是 pinky README 里写死的设计前提。
- **世界模型收敛到「单一可微分模型 + 全身控制」**：supermimic 用一个可微分世界模型直接训练人形全身运动追踪（同时支持广义坐标与最大坐标两套表示），而 HN 当日 214 分的《600 次实验后我对 JEPA 世界模型的发现》指出：把预测器换成完美物理模拟后收益有限，**真正的瓶颈在「嵌入空间里的规划」而非预测精度**。两条独立信号指向同一个结论——世界模型的竞争焦点正从「像素预测准不准」转向「动作规划选得对不对」。
- **国产模型走出两条不同的超车路径**：速度路线是 NaiveAI 的 Naive-N0.5-Flash（自研 NaiveRT + 稀疏注意力，实测单秒峰值 2100 Token/s，中位响应 3.1 s）；深度路线是无界前沿开源 Fx-Bio-1031（生信垂域，BioMysteryBench 困难子集 Pass@5 70.59%，甩开 GPT-6-Astra 的 47.06% 与 Opus-5 的 52.94%，且开放完整权重、数据不出域）。**不再跟通用能力硬拼，而是拼单位 token 成本与单场景天花板**——这与 MiniMax 开源 H3-Image 后量子位提出的「垂直模型由通用模型串联、总效用更高」是同一套产业逻辑。

## 🎯 AI 重点关注

- **英伟达换帅是一次「治理危机 → 资本开支定价权」的三重传导**：第一重是钱——105 轮/年的巨头兜底式融资断档，一级市场估值锚重排；第二重是合规——权重指纹显示 Blackwell 管制被绕过，英伟达自身成了出口管制风险的被告；第三重是生态——A 股产业链 11 月 13 日批量重挫（天孚通信、胜宏科技约 -10%，生益科技跌停，中际旭创约 -8%），但供应商与西门子均回应「合作未受影响、算力卡价格无显著波动」。**真正的观察指标不是股价，而是 11 月 17 日的 FY2027 Q3 财报里算力订单与授信担保口径的变化**——那才是整个 AI 资本开支周期的新锚。
- **Agent 的竞争焦点已经离开「模型」，落在「执行权 + 审批权」**：ChatGPT Wallet 让 Agent 替你付钱、OpenAI 解散机器人团队让通用模型直驱物理任务、pinky 让 Agent 操作真机手机且**审批由网关强制而非提示词约束**、agentes-chat 让 Agent 成为有预算的工作区成员。四件事指向同一个结论：**2027 年 Agent 产品的护城河不再是回答质量，而是宿主能否安全地把「行动权」授予模型**。谁把审批做进基础设施，谁就拿到了 Agent 商业化的入场券。
- **国产模型的两条超车路径已经分野，且都不再依赖通用能力硬拼**：Naive-N0.5-Flash 拼的是单位时间产出（2100 Token/s、3.1 s 中位响应），Fx-Bio-1031 拼的是单场景天花板（BioMysteryBench 困难子集 70.59% vs GPT-6-Astra 47.06%）并以完整开源权重 + 数据不出域作为差异化。**「更快」和「更深」正在取代「更强」成为国产模型的两条主线**，而 MiniMax 开源 16MP 原生 4K 的 H3-Image 并附赠 prompt-writing skill，则说明垂直模型 + 技能化分发已经是一条完整可走的商业路径。
