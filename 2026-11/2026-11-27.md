- **算力的物理边界第一次以「地理」形式显现，国产模型的迭代周期被拉长**：英伟达已通知戴尔、超微**暂停向马来西亚、新加坡、泰国、印尼发运搭载其芯片的服务器**，起因是中国企业从这些国家的远程数据中心「租用」算力绕过芯片出口限制（美国商务部本月已关闭该漏洞）；Institute for Progress 估计这类远程数据中心供应了**中国约 24% 的 AI 算力**。同时英伟达开始要求云客户「少接中国企业的生意」并披露终端用户身份。传导结果已经落地：**智谱约 3 万亿参数的 GLM-5.5 从 11 月推迟到 2027 年 Q1**（先用 7500 亿参数的 GLM-5.4 顶上，称新设计让它「能跟上 2–3 万亿参数的系统」），**月之暗面因拿不到海外算力，迭代周期可能从 6 个月翻倍到 12 个月，Kimi K4 大概率推迟到 2027 年中**。DeepSeek 内部估计已落后美国模型约 9 个月且差距在扩大。**判断：出口管制的有效靶子已经从「芯片流向」扩展到「算力可及性」与「模型权重来源」两端，这才是真正改变中美 AI 竞争节奏的一步。**

- **Agent Skills 已经分化成「官方标准」与「个人方法论」两条路线，而且后者更受欢迎**：今天日榜前十里 6 个是 Skill 仓库、周榜前五里 4 个，但它们明显分成两派——**官方派**：`google-labs-code/stitch-skills`（Google Labs，设计工具的官方技能规范）、`GoogleChrome/modern-web-guidance-src`（Chrome 官方维护 224 条 Web 指南）、`obsidianmd/obsidian-skills`（Obsidian 官方，README 里直接列了 Antigravity / Hermes Agent / GitHub Copilot 的安装方式）、`mjmirza/app-store-compliance`（把 124 条拒审模式与 114 个合规截止日期写成可执行的前置 guard）；**个人方法论派**：`obra/superpowers`（327,494 星）、`mvanhorn/last30days-skill`（75,762 星）、`kajisho5/ffmpeg-skill`（11,536 星）、`tradermonty/claude-trading-skills`（8,602 星）。**判断：官方派卖的是「协议正确性」，个人派卖的是「经验密度」——而 star 数说明市场给个人派付了更高溢价，因为 Agent 需要的是「怎么做对」而不是「接口长什么样」。**

- **Agent 的成本优化出现第五条路径，而且是最反直觉的一条**：`sous-labs/songe` 的思路是——**在 Agent 安静、显存空闲的时候，用这些算力反向训练你自己的模型**：读取对话中的纠正与明说的偏好写成短小的练习场景，用旧模型当老师生成新版本，新版本只有在表现更好时才被启用，无账号、无遥测、默认不上云。此前已有四条：`INK-Q/agy-fast`（1,718 星，Google Antigravity 的 MCP 加速插件，**砍掉 34% 的 LLM 回合、31% 的 token 配额、40% 的上传流量**）、`EL4CTEO/fast-anything`（只重写 5% 慢代码、行为等价性证明）、`daoif/tokless`（AST 代码骨架 + 盲读防护 + token 账单审计）、`SodovaFo7/claude-code-unlimited`（自动轮换 Claude Code 会话）。**判断：当厂商收紧额度、开发者开始自己找便宜路径时，最有想象力的那条路径是「不花钱，而是把花不掉的时间用起来」——这是把算力从成本项变成资产项。**

- **「大上下文」这件事第一次被官方研究否定，而替代方案是「笔记」**：The Decoder 报道，英伟达研究人员撰文论证语言模型往往**不需要用满整个上下文窗口**——长上下文既慢又贵还容易出错；实验中**周期性摘要 + 定向关键词搜索通常能以一小部分成本达到全上下文的效果**，并提出一类只用短笔记工作的新模型。对照今天的 GitHub 生态：`firecrawl` 的卖点正是「把网站转成干净 markdown 让 Agent 省 token」、`last30days-skill` 把信号压缩成固定几行、`songe` 把偏好压缩成短练习场景。**判断：上下文窗口的军备竞赛已经进入「反向工程」阶段——厂商卖 100 万 token，但真正赚钱的用法是让模型只读该读的那 5%。这直接决定了「端侧小模型 + 检索 + 摘要」这条架构会不会在 2027 年赢过「更大的上下文」。**

## 🎯 AI 重点关注

- **AI 科研的瓶颈已经确定性地从「模型能力」转移到「组织生产与并行证伪」** —— pequalnp.com 用 381 个智能体、三天 10,936 次会话跑出 2,456 条已验证引理，同时把总引理数从 811 推到 5,934；GitHub 被并发压到限流、迁移进付费企业组织后每次仍只能并发 6 个任务、50 多个验证排队干等；800 多条被证伪主张被单独立「墓地」归档。**判断：当 AI 解题变成一场需要调度、证伪、排队、限流的生产活动时，它的稀缺资源就不再是模型，而是「验证基础设施 + 结论审计能力」。** 这一天里 Anthropic 与 OpenAI 同日各自用 7.3 万行与 44 万行 Lean 代码证明 VP ≠ VNP、OpenAI 给出 ω = 9/4 的精确答案、Scott Aaronson 写下「我们不会再看到一次复杂度理论的大陆被发现」——**成果的边际成本正在归零，但成果的验收与消化的边际成本没有下降**。**这个矛盾会在未来 6–12 个月内变成数学界最尖锐的议题：审证书的人，正在成为新的瓶颈职业。**

- **出口管制的靶子已经从「芯片流向」转向「算力可及性 + 模型权重来源」，而国产阵营的第一反应是架构而非堆卡** —— 英伟达暂停向马来西亚、新加坡、泰国、印尼发运服务器（远程数据中心供应中国约 24% 的 AI 算力），并开始要求云客户少接中国客户业务、披露终端用户身份；结果是 **GLM-5.5 推迟到 2027 Q1、Kimi K4 或推迟到 2027 年中、DeepSeek 内部承认落后约 9 个月**。**判断：这一轮管制的实际杀伤力大于再加一档芯片限制，因为它切断的是「用别人的卡训自己的模型」这条近两年的主要杠杆。** 国产的应对已经分化：**智谱用 Loop Transformer、双门控与 KV Cache 远近拆分把 7500 亿参数的 GLM-5.4 做成「能跟上 2–3 万亿参数系统」的架构解**，另一端是加大 RL 数据投入的数据解，而蔚来给出的第三条路更狠——**隐式世界模型把仿真从「渲染像素」换成「预测特征空间」，训练过程百倍级加速、综合训练效率提升 5 倍**。**架构解与数据解的共同前提是国产卡要撑得住 2027 年的万卡级训练，而这又回到 HBM 产能这个物理约束上。**

- **Agent 的成本优化已经进入「五条路径并行」，而最反直觉的那条把算力从成本项变成了资产项** —— 官方派（OpenAI 合并 Chat 与 Work 计量器、GPT-6.2 被第三方测出推理量显著下降、Anthropic 9 月合并 Claude 与 Cowork）在收紧额度，个人派在自救：`agy-fast`（LLM 回合 −34%、token 配额 −31%、上传流量 −40%）、`fast-anything`（只重写 5% 慢代码 + 行为等价性证明）、`tokless`（AST 骨架 + 盲读防护 + token 账单审计）、以及最新的 **`sous-labs/songe`：在 Agent 安静、显存空闲时用这些算力反向训练自己的模型，新版本只有在表现更好时才启用**。**判断：当厂商的额度越来越紧，最高级的应对不是省钱而是「把花不掉的时间用起来」——这意味着 Agent 的运行时本身正在变成一个训练基础设施**，而这个转向会重新定义「谁来承担推理成本」这个问题：**过去是用户按 token 付费，将来可能是 Agent 自己生产 token。**
