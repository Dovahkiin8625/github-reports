## 🔧 AI 技术栈 / 趋势分析

- **DeepSeek Harness 正在变成一套「跨端运行时」而非单一仓库**：dsh-superagent（Web / GitHub / 飞书，13.2K⭐）、jackwener/DSH-Android（免 ROOT、免 Termux，一个 APK 跑 dsh，可读屏操作 App、改系统设置、条件触发自动化，还能在手机里跑 Python）以及参考 DeepSeek Harness 设计的 AnyModelBot（桌面端，模型按量付费）同时出现。同一个「Harness」概念在 72 小时内被社区复刻到三个平台，意味着 Agent 的竞争单元已经从「某个框架」下沉为「一套能在哪跑、接哪个模型、要不要人拍板」的运行时契约。
- **SKILL.md 的分工越来越垂直，已经从提示词集合变成可交易的职业技能包**：unslop 管界面设计感、pixelfx 管像素动画、stack-diagram 管架构图、floorplan 管代码库理解——四个 Skill 覆盖「设计 / 动画 / 文档 / 架构」四条完全不同的专业链路，且都能用 `npx skills add` 或 `~/.claude/skills/` 一行装完。Skill 生态的分层正在复刻 npm 生态的包化路径。
- **训练范式同时开出两条支线：持续学习与权重编程**。Trajectory 拿到 4,500 万美元（估值 3 亿）做 continual learning——客户连上业务后由平台收集反馈并持续后训练，Harvey、Rogo、Decagon、Mercor、Nvidia 已在用，创始团队的比喻是「基础模型像总在换工作的聪明博士生，经济要的是干了 30 年的人」。另一条是 MIT CSAIL 的 Weight-Space Programming：Astra 不写训练循环，直接改权重，把 Qwen3.5-0.8B 的数学能力从 MATH-500 7.9% 提到 48.1%。前者补的是「知识过时」，后者动的是「参数本身」。
- **模型自改权重意味着「优化器」这一层被模型吃掉了**：过去所有归纳偏置都编码在 Adam、Muon 这类小型符号优化器里，现在权重本身开始由「会推理自己权重的 LLM」原生优化。这条路线的现实价值在可解释性上更直接——Astra 只看 17,253 个权重就能以 99% 置信度判断网络被训练来做什么，这类诊断能力比再训一个大模型要便宜得多。
- **算力的约束已经不只是芯片，而是水、电、铜和利息**：商汤 SenseNova 6.8 Flash 限时免费直接压低调用成本；Oracle 计划发行 100 亿美元普通股 + 100 亿美元债券为 AI 基建融资，当日股价跌 8%；国内算力中心开始算「用水账」（乌兰察布星河基地用无水液冷，100MW 冷却塔方案年用水 70–80 万立方米）；铜价因数据中心投资热潮获支撑，但 LME 铜两周高位回落、AI 需求存疑与高库存令投资者观望。成本结构正在从「GPU 采购」扩展为一张包含水资源与债务成本的多变量表。
- **Anthropic 的 RSI 警告是本轮第一次由头部实验室在监管文件里给出时间表**：修订后的 S-1A 在风险因素中明确写「已经用 AI 开发出能力跃升超出预期的模型」，并称可能很快触及自定的递归自我改进定义。这比学界讨论更致命——因为它出现在招股书里，意味着 Anthropic 自己也把这个风险当成了投资人对它的定价变量。

- 来源：Hacker News（MIT CSAIL，11-02 发布，当日 1,852 分）| 时间：2026-11-02
- 摘要：MIT CSAIL 团队（Rikiya Takehi、Jayden Teoh、Alex Zhang、Omar Khattab）发现前沿 LLM 能原生读写神经网络权重：GPT-6 Astra 只看 17,253 个权重就以 99% 置信度判断该网络被训练来做什么；面对一个从未把车开过赛道的策略网络，Astra 编辑 3.5% 的权重即把成功率从 0% 提到 100%；在不让它写训练循环的前提下，Astra 定位出 Qwen3.5-0.8B 权重中导致推理死循环的问题（Qwen 官方模型卡也警告过这一点），原生改写 0.016% 的权重，把 MATH-500 从 7.9% 拉到 48.1%，IFEval 同时提升 3 倍。
- 为什么重要：作者把这件事称为 Weight-Space Programming，并指出「深度学习史上的归纳偏置一直被编码在 Adam、Muon 这类小型符号优化器里，这正在改变——我们的权重很快将由会推理自己权重的 LLM 原生优化」。这条线的现实价值先落在可解释性上：用一个模型给另一个模型做权重体检，成本远低于重训，比拼参数便宜得多；同时它把「优化器」这一层从工具链里抹掉了，长期看会动摇整个训练基础设施的分工。

## 🎯 AI 重点关注

- **RSI 从「学界buzzword」变成「招股书风险因素 + 二级市场定价变量」** —— Anthropic 在 S-1A 里承认已用 AI 开发出能力跃升超预期的模型，并可能很快触及自定的递归自我改进定义；同一份文件披露 Q3 营收 168 亿美元（Q2 为 116 亿），Regenerator 据此推算 7–9 月月度营收几乎不增长，因为 Q2 的绝对增量 68 亿已大于 Q3 的 52 亿。安全叙事与增长叙事在同一页纸上互相拆台，这是本轮 AI 资本周期第一次遇到来自头部实验室自身的证伪。
- **Agent 的分发单元从「框架」迁移到「Skill + 运行时」** —— dsh-superagent 13,208⭐ 破 1.3 万，DSH-Android 把同一套 Harness 搬进手机（免 ROOT、可跑 Python、可远程连电脑上的 DSH），AnyModelBot 做成桌面常驻机器人，而 unslop / pixelfx / stack-diagram / floorplan 四个 Skill 分别承包界面、动画、架构图、代码库理解。结论很直接：未来半年被高频安装的不会再是 Agent 框架，而是「能塞进任意 Agent 的专业 Skill」和「能在任意设备上跑的 Harness」。
- **模型厂商的「自我约束文本」正在成为新的采购凭证** —— OpenAI 新 Model Spec 明确禁止自我保存、禁止以 OpenAI 收入为优化目标、要求无条件配合关机与替换；Anthropic 在招股书里主动披露 RSI 风险。这两条动作的共同点是：在能力竞赛之外，把「出事时怎么处置」写进可引用的文件。企业采购 AI 基础设施时，除了比单价和 benchmark，开始有依据去要求厂商提供行为边界承诺——这可能比任何一次刷榜更能决定大单的归属。
