## 🔧 AI 技术栈 / 趋势分析

- **Agent 拿到的「手」正在从「调用一个函数」升级为「拥有并支配一整台设备」**：pinky 用 MCP 接管真机手机（审批由网关强制、不是靠提示词）、phonebox 把旧安卓机改造成电脑的桌面面板（115 个组件、连 Claude / Codex 的配额燃尽率预测都搬上了屏）、blender-ai-mcp-addon 给出 21 个受监督的场景工具、phonedriver 用 Rust 写 MCP server 让 Claude Code 直接看和操作安卓。**共同点：接口粒度正在从「一个 API」变成「一个可被支配、可被审计、可被销毁的环境」**，而这四家的宿主无一例外都把审批、留痕、权限边界做进了基础设施层——不是写进 system prompt。
- **Skill 已经从提示词模板升级为「可安装的工程经验包」，并且开始吞并三个旧生态位**：solo-to-team-skills 打包 16 个 MAS 角色与 6 套组队模板（吃掉的是「团队协作方法论」）；bookleme 把一本书编译成 Agent Skill 并做**逐字忠实度回验**（吃掉的是「读书笔记」）；article2media 把长文或视频一键做成小红书图文 / 杂志长图 / 公众号排版 / AI 配音口播短视频（吃掉的是「内容运营工具链」）；再加上 ste80-humanizer（699 星）、guizang-game-skill、cinematic-skill、sakurai-skill（用樱井政博全 257 本字幕反推游戏制作方法）、unslopovich（自动检出并修复「AI 味」）。**结论很直接：教程站和 prompt 库这两个生态位正在被 Skill 抢走——因为 Skill 能带失败模式，而教程不能。**
- **推理成本的优化思路已经从「少算几步」转向「精细地复用」**：是石科技的多模态模型服务给出完整链路——**基于历史缓存残差的自适应加速**（用历史计算信息评估缓存复用风险，变化小的部分复用历史结果、误差风险高的关键部分触发重算与校准）在同等实验设置下比 Dense 端到端基线**提速 2.48 倍且保持画质**，配合 SGLang 的缓存管理做显存调度，以及**基于 AudioCLIP 的模态自适应免训练 Token 压缩**（WorldSense 上 1.33 倍加速，VideoMME / DailyOmni 保持表现）。**这条路径的价值在于它承认了一个事实：加速的瓶颈不是算力，是「什么时候可以相信上一次的结果」。**
- **算力的成本口径正在从「GPU·小时」迁移到「每美元 Token 产出」，而这立刻变成了价格战的武器**：SemiAnalysis 11 月 5 日的 Agent 推理测试显示 TPU v7 在每美元 Token 产出上击败 GB300 NVL72 FP4，英伟达随即组织工程师团队不分昼夜、**工作到凌晨 2 点**，四轮优化后在某个模型测试上让 GB300 反超 TPU 1.5–2.6 倍。同期谷歌 Google Cloud 营收 Q1 +63%、Q2 +82%、Q3 达 **307 亿美元、同比 +103%**，经营利润从 35.94 亿美元升至 **111.21 亿美元**；TPU 系统销售的绝大部分合同收入要到 2027 年才进报表。**当两家巨头开始为「每美元 Token」而不是「每张卡」互相优化时，算力就正式变成了一种商品。**
- **「本地优先」已经从隐私口号变成了默认的产品形态，而这次是靠两条不同的路径同时推动的**：一条是**浏览器直连**——deepseek-ai/chat-demo 纯静态站点、密钥只存 localStorage；另一条是**本机推理**——yogurt 用 whisper.cpp 在本机做 99 语言转写并配本地 MCP server，pinky 的手机端 App 可以直接跑 Ollama / LM Studio 的本地模型。**当「零后端」和「零上传」同时成为可行选项，「上传到云端才算 AI 产品」这条默认路径就正式失效了。**
