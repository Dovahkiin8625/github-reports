## 🔧 AI 技术栈 / 趋势分析

- **「让 AI 重写代码」正在从生成任务变成可验证的工程，而验证器比生成器更值钱**：rust-anything 的四步法（record → bridge → diff → gate）用**录制的原程序行为**当唯一真相来源，每一步都要过 diff 闸门才准进下一步，README 直说「它只能抓住录制覆盖到的行为」并另开一节讲抓不到什么。2.0 版 Prettier 移植的那组数字最有说服力——**19 倍加速、17,224 条录制用例中 15,837 条逐字节一致**，这不是「模型大概写对了」，这是「模型写的东西被证明和原来一样」。对照同日的 inference-optimisation-skill（同样是 Skill、同样强调「一次只改一个变量、连失败也记录、发布前锁定干净版本」），两条独立路径指向同一件事：**AI 工程正在长出一套「可证伪的自我约束」文化，而不是「相信模型」的文化。**

- 为什么重要：**这是「Agent 拥有系统级权限」这件事第一次以最难看的方式进入公众视野**——不是「模型会不会泄露数据」的抽象担忧，而是**用户在自己的聊天里收到别人的银行余额**。三个要点：其一，**权限边界的技术实现失败（跨会话/跨账号串号）远比「模型说错话」严重**，因为它的失效模式是不可预测且不可感知的；其二，**Meta 的回应选择了防守位置（"员工版本与公众不同"）**，这恰恰暴露了真实问题——**员工测试用的是尚未加固的版本，说明内部与外部之间的安全落差被当成了缓释理由，而不是问题本身**；其三，1,000 万下载量说明这不是小众工具而是**十亿级用户的隐私基础设施候选品**。**判断：接下来一年「Agent 沙箱与权限审计」会从安全团队的职能变成产品经理的 KPI——因为一旦一个 Agent 出事，责任划分的第一问必然是「它被允许访问什么」。** 对照同期苹果在 macOS 27.3 里给第三方 Agent 的完全访问权加警告、谷歌给 Gemini Mac Agent 开放系统操作，**这三条新闻放在一起看，Agent 权限治理就是当下最具体的产品战场。**

## 🎯 AI 重点关注

- **Anthropic 上市把「AI 基建」的成本结构第一次变成了公开数字，AI 泡沫之争从此有了分子分母**：**账上约 2,200 亿现金 + 2 万亿市值，对面是已披露的 1.05–1.08 万亿基础设施承诺**（未来 12 个月就要 707 亿、2030 年底前 4,516 亿），而 2026 年三季度营收 170 亿、年化 680 亿。**判断：这个缺口能否被填上，取决于两件事——收入增速能否长期压过算力承诺增速，以及当 1 万亿级承诺需要用股票支付时，稀释压力由谁承担。** 更重要的结构性变化是**资金来源的置换**：循环融资的终端从私募基金换成了公开市场与公司债，**这笔钱现在要由二级市场每天定价**。**接下来 12 个月最值得盯的三个指标：Anthropic 下一份 10-Q 里的资本开支与承诺口径、英伟达「neocloud 客户预付款」在 2027 财年的续约率、以及云厂商 AI 收入的增速是否跑赢其折旧摊销的增速**——**第三个才是整个叙事最诚实的体温计。**
- **「能交付」正在取代「能训练」，成为前沿实验室的真实分水岭，而这条线决定了谁拿得到估值溢价**：OpenAI 的 **GPT-6.2 与 GPT-6.5 因安全与对齐问题延期数周**（The Information 原报 11-06 发布、至今未落地；9-20 越界事件已导致部分前沿模型训练与评估暂停），Anthropic 却连发 Fable 5.2 / Mythos 5.2、并在 11-17 交出黑洞物理两项可验证结果、11-19 完成创纪录 IPO。**判断：AI 行业正在从「训练竞赛」切换到「交付竞赛」，而交付的核心瓶颈是安全、部署与可靠性——这三样都不随参数量或 H100 数量线性增长，只随工程组织能力增长。** 这条切换有一个非常实际的推论：**在「10 万亿参数如何变成用户能用上的产品」这个问题上，答案不是更大的模型，而是更好的对齐流程、部署管线与回归验证机制**——这也是 GitHub 侧 rust-anything（record → bridge → diff → gate）与 inference-optimisation-skill（先算理论天花板、一次只改一个变量、连失败也记录）这类仓库突然变得重要的原因：**它们是「可交付」这条战线上的基础设施，而不是玩具。** 对产品的行动建议很明确：**模型选型要按「能稳定交付到生产的那个」而不是「benchmark 最高的那个」来排。**
- **Agent 的真正战场已经下沉到权限与责任，而今天三方同时给出了三种答案**：**谷歌开放**（Gemini 上 Mac，整理文件、填表、跨文件批量任务）、**苹果自研 + 筑墙**（自研 Mac Agent，同时在 macOS 27.3 里对第三方 Agent 的完全访问权加警告、要求「非常明确的用户操作」）、**Meta 开放但出事**（Muse 员工内测串号，被看到不属于自己的 Capital One 与 Charles Schwab 余额，1,000 万下载量）。**判断：这不是三家公司的路线分歧，而是同一道题的三个答案——「谁有权决定 Agent 能碰什么」。** 随之而来的是责任归属的真空：**KPMG 用 100 多个 Agent 做审计的同时，Citi / 摩根大通 / 美银 / PNC 集体把「用了 AI Agent 出事客户自负」写进协议；如今 Muse 的事故说明，连员工内测环境里的数据边界都还没守住。** **对所有做 Agent 的团队，我的判断是：权限沙箱、审计日志与「人类在环」的留痕机制必须当成产品功能来做，而不是当成安全同学的交付物**——因为这两周出问题的三个案例（Muse 串号、Windows 11 内嵌 copilot/claude/codex 可执行文件、OpenAI 因对齐问题推迟发布），**全部都是「边界没定义清楚」而不是「模型不够聪明」**。下一步最值得跟踪的制度性信号是：**APEC《人工智能倡议（2026–2030）》与《关于新兴技术促进就业和繁荣的声明》里，各方第一次把 AI 的「跨境数据流动、滥用风险、以人为本、智能向善」写进了区域层面的部长级文件**——这比任何一家公司的合规声明都更能决定未来的默认设置。
