## 🔧 AI 技术栈 / 趋势分析

- **Agent 的竞争焦点从「单次回答质量」转向「多任务并发 + 长期存活」**：DeepSeek dsh-superagent 用 Router / Worker 分层 + 投机执行 + Watchdog 自愈，把 20 项协作任务下的完成时间压到中位数 12.4 分钟、95 分位 15.7 分钟，而传统单 Session 方案的 95 分位高达 29.5 分钟；同时给出成本账——取消事件直通后 Router 决策次数 +30%、缓存 token +37%。配合 wangzan101/Mika 这类端侧常驻 Agent，「Agent 是同事不是工具」已经从概念进入仓库量级。
- **SKILL.md 正在取代 prompt 成为 Agent 生态的「应用商店单元」**：今日 Top 10 里 unslop（去 AI 味界面）、pixelfx（像素特效）、Motionsites-AI/claude-skill（电影感落地页）三个仓库本质都是纯 Skill 包，`git clone` 到 `~/.claude/skills/` 或 `~/.agents/skills/` 即装即用，且分工越来越垂直——Skill 从「提示词集合」进化成了可交易的专业能力包。
- **AI 生图工具的「数据层 + 多协议直连」已成标准形态**：ai-pose-gallery-zh 用 11,568 张本地高清图喂满 4,345 条参考数据，nvzhuang 用 Go 后端接 GPT Image 2 / 豆包 / Gemini，两边都把 ComfyUI 当一等公民。开源生图工具的竞争壁垒已经不在模型调用，而在「结构化中文素材 + 自建工作台 + 不被单一 API 锁死」。
- **世界模型同时占住了算法、评测与硬件三个位置**：算法侧，姚期智团队的 AWM 用 Lean 4 形式化证明 ARC-AGI-3 关卡在给定步数下无解；评测侧，西湖大学成立世界模型研究中心并孵化 Awomo，Momenta 系新芯航途 X7 Ultra 直接用 R7 世界模型而非实验室基准来测芯片（700 TOPS、内存带宽降 80%、能效 +100%）；商业侧，a16z 投 1,700 万美元给做建筑业世界模型的 Dream——这是「世界模型」第一次同时出现在三个完全不同的产业语境里。
- **「小模型 + 递归自我改进」在垂直任务上跑通了**：OXR 用 1.3B 参数在 OmniDocBench(97.18) / olmOCR-Bench(87.84) / DocParsingBench(87.76) 三榜登顶，单张 RTX PRO 6000 解析 100 页文档 101 秒。核心机制不是更大的模型，而是把「预测对不对」变成可自动测量的信号——按 Correct / Wrong / **Uncertain** 三分类（保留 Uncertain 以免把模型的犹豫强行标成确定标签）、再做归因聚类与合成数据回流。垂直任务的自我进化比通用堆参数更现实。

### 7. [Proving and Improving the Platonic Representation Hypothesis with JEPAs](https://arxiv.org/abs/2610.39302)
- 来源：Hacker News / arXiv（2610.39302，10-29 提交）| 时间：2026-11-01
- 摘要：论文把「柏拉图表示假说」（不同模态的模型规模上去后会收敛到同一世界表征）从猜想变成了定理：证明 JEPA 架构在任意数量模态上分别训练时，只要正样本对是同一场景的两个「好视角」，学到的表征只差一个旋转。论文同时指出 next-token 预测本质上是用「坏视角」训练的 JEPA，这解释了语言模型只能靠规模才能对齐视觉。
- 为什么重要：这是今天 HN 上含金量最高的一篇——它给出了可操作的结论：好视角（同一场景的多观测）比单纯堆规模更有效，好视角比 next-token 少用 42 倍训练样本就能达到同等对齐水平；一个 1.09 亿参数的文本 JEPA 对齐 DINOv2 / CLIP 图像编码器的效果超过所有评测过的最大 72B 语言模型。对多模态团队而言，「正样本对怎么构造」从此有了理论依据，而不再只是调参玄学。
