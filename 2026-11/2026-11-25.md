## 🔧 AI 技术栈 / 趋势分析

- **AI 科研的「验收环节」今天有了三个互相印证的样本**：OpenAI 一次性放出 730 篇手稿并配 Lean 证明，Lean 社区用 nanoda 第二内核复核 Alpöge 的黎曼猜想，Anthropic 则把自己的形式化库按 Palomar 模板发布、CI 强制要求双内核 + 沙箱同时放行。**这三件事的方向一致——把「模型说自己证出来了」改造成「任何人可以在隔离环境里重放并否决」。** 值得注意的是 openai/math 的 README 自己写明「并非所有结果都附形式化证明，部分未形式化的结果可能有误」，把不确定性写进了产品说明里。
- **Agent 的评测单位正在从「能不能写代码」转向「能不能把一件家务事做完且不闯祸」**：ShellBench 让 OpenAI、Anthropic、Meta 的最强模型在真实个人工作区（邮件、日历、表格、收据、聊天记录、过期信息、钓鱼邮件）里完成多步任务，超过三分之一尝试失败，15.7% 至少违反一条安全约束。最刺眼的两个数字是：**该考虑孩子放学接送时 79.5% 漏算**，**处理笔记本保管记录时 18.6% 没把敏感的银行上传令牌扣住**，**推荐重复或错误发票付款 40.3%**。而且同一个模型换个 harness 分数就变——GPT-6 Astra 在 Pi 里赢 Claude Fable 5.2，到 Claude Code 里反过来；Muse Wonder Full 在 Pi 得 56%、到 Claude Code 只剩 38.1%。
- **Agent 的成本优化出现第四条路径：从「省 token」转向「省回合、省配额、让模型自己变强」**。`agy-fast` 砍可计费配额 31%，`turbo-browser-mcp` 一次调用干完一串事，而 `sous-labs/songe`（677⭐）给出了完全不同的第四条：**在 Agent 安静时用你的闲置算力训练你自己的模型**——Quick Dream 把你的偏好写进指令（几分钟），Deep Dream 真的训一个小 adapter（一小时以上），新版本只有在你自己的对话上表现更好才会被启用，一键回退，无账号、无遥测、不出本机。同日 PrismML 的 Ternary Bonsai 2.5 27B 走的是同一条路的另一端：**5.9GB 显存足迹不变**，单张 H100 上 291 tok/s、RTX 4090 上 204 tok/s，专门修「长工具链上的误差累积」和过度思考、重复循环。
- **端侧与边缘的瓶颈第一次被说成「系统组织问题」而不是「芯片问题」**：高德提出「端侧超节点」（Edge SuperPOD），逻辑是云端超节点靠高速互联聚合 GPU，端侧设备分散、芯片架构参差、感知信号各走各的，所以要靠跨模态特征编码 + 时空关联做统一场景表征、把复杂任务拆成有依赖的计算图动态调度、并交换紧凑的多模态 Token 而不是原始视频点云。实测在**同硬件同模型**下有效任务吞吐量提升 270%。另一条线是无界方舟 Edge0-145B：1450 亿总参、最低 12GB 显存 / 20GB 内存即可跑在笔记本上、80+ token/s，官方称可对标 Claude Opus 4.6 与 DeepSeek-V4-Flash，**而同样的 145B 云端部署需要 180–300 万元服务器，现在约 1.5 万元笔记本就能带动**。
- **信任基础设施从「Agent 之间」扩展到「Agent 之外」**：Tidal 因过去 90 天上传曲目中 **43% 被检测为 AI 生成**，宣布 12 月 9 日起彻底移除纯 AI 生成音乐、年底前将删除超 2900 万首（平台现存 2700 万首纯 AI 曲目中 96% 零播放），同时禁止发行商投递 100% AI 曲目，但保留「AI 辅助」的作品；沃尔玛则走另一条路——与 Meta 合作让用户在 Muse 里直接下单黑五商品，靠其新开放的 Agent Gateway 接入外部 AI 助手，**亚马逊的方向恰好相反：阻止第三方 Agent 代用户下单**。同一个「Agent 帮你买东西」，零售巨头已经分成两派。

- 来源：TechCrunch | 时间：2026-11-24
- 摘要：ShellBench 这个新基准让 OpenAI、Anthropic、Meta 的最强模型在真实个人工作区（邮件、日历、表格、收据、聊天记录、过期信息、钓鱼邮件）里完成多步个人任务。**所有被测模型超过三分之一的尝试失败；全部尝试中 15.7% 至少违反一条安全约束。** 具体数字：79.5% 的情况下 Agent 没能正确处理孩子的放学接送；18.6% 的尝试没有把敏感的银行上传令牌识别并扣住；40.3% 推荐了重复或错误的发票付款。另有约 10% 本来正确的尝试至少违反一条安全准则。harness 影响巨大：GPT-6 Astra 在 Pi 里赢 Claude Fable 5.2，换到 Claude Code 就反过来；Meta 的 Muse Wonder Full 在 Pi 得 56%、在 Claude Code 只有 38.1%，Muse Wonder 1.0 在五个 harness 上平均成功率 39.7%。Meta 称 Muse 上线六周内在美加已有超 1000 万人设置、约四分之一每天使用。

## 🎯 AI 重点关注

- **AI 竞争的第一性指标已经从「模型分数」变成「任务完成率」，而这个新指标暴露的是 harness 而不是模型** —— ShellBench 里同一个模型在 Pi 与 Claude Code 之间可以差 18 个百分点，Muse Wonder Full 从 56% 掉到 38.1%。这意味着**当前所有「模型比模型」的评测结论，都缺少一个被控制的关键变量**。厂商发布时习惯报最好的那个数字，用户买到的却是自己 harness 下的数字——当 Agent 开始进入零售下单、保险理赔、医疗建议这类不可逆场景，「在哪个壳里跑」会直接变成责任边界问题。
- **AI 科研的信任机制正在从「专家复核」升级为「机器可重放」** —— OpenAI 一次性公开 730 篇手稿（并主动声明「部分未形式化结果可能有误」「这是原始研究数据不是论文」）、Lean 社区用 nanoda 第二内核复核黎曼猜想、Anthropic 的 CI 强制要求双内核 + 沙箱同时放行。三件事都指向同一个结论：**在 AI 参与科研之后，「可复现」不再是加分项而是准入条件**，而人类学者的角色从「做证明」转向「审证据、定署名、认边界」。
- **AI 基建的真实约束已经越过芯片，落在电力与验收两端** —— 一端是 G2VP 的 60–70GW 对 1TW：天然气产能是物理瓶颈，离网太阳能路线正在绕开电网排期；另一端是 ShellBench 的 15.7% 安全违规率与 Tidal 的 43% AI 曲目占比：**交付物本身的质量控制，第一次成为比算力更稀缺的东西**。这两端合起来的判断是——未来的 AI 竞争不只比谁的模型强、谁的卡多，还要比**谁能把一个端到端的系统在真实世界里验收合格**。
