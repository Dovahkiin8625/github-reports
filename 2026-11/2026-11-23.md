## 🔧 AI 技术栈 / 趋势分析

- **「验收工序」正在从 AI 科研的附属品变成标准化零件，而 GitHub 上已经出现了这个零件的标准件**：昨天 Lean 与 Mathlib 社区联合认证了 Alpöge 的 1,700 万行黎曼猜想证明，今天 Alpöge 与 Buckmaster 的 79 页无外力 Navier–Stokes 爆破证明同时公开 Lean 代码。而 `leanprover-community/riemann-hypothesis` 这个仓库当天冲到 626⭐，它做的事极其具体：**把 Alpöge 提交从 `alpo.ge/remark.pdf` 抓下来的原版镜像下来**（commit `40e56bab`，未修改），然后**配一套独立 comparator**——`src/Main.lean` 证明那五条定理，`src/Challenge.lean` 用 `sorry` 占位同样的五条陈述（且只 import Mathlib），Comparator 检查 Main.lean 恰好证明了这些陈述、**除 `propext`、`Quot.sound`、`Classical.choice` 外未使用其他公理**、**且 Lean 内核与 nanoda 两个独立内核都接受该证明**。README 里还写明了一个很实在的工程约束：**发布源码是为 Lean 4.33.1 写的，那个版本既没有 `lake comparator` 也没有 `leanexport`，所以校验 40e56bab 本身需要两套工具链**。**判断：当「独立复核」这件事本身也能被封装成一条 `lake comparator` 命令时，AI 科研的准入门槛才真正从「作者的学术声誉」转向「任何有台 Linux 机器的人都能跑的验证脚本」——这对做工具的人是明确的路线图：下一个价值洼地是验证器的易用性，不是更强的模型。**
- **Agent Skill 的分发已经进入「npm 时刻」，但信任层是空白**：`signet` 把这件事说得很清楚——**大多数注册表只是目录（metadata 进、搜索出），而 Agent 与 Skill 的分发量已经到了需要「印玺」的规模**。它给的方案是「图谱优先 + 五层验证 + 密码学信任 + 透明日志」：**逻辑身份与发布快照分离**（`AGENT`/`AGENT_VERSION`，带 supersession / revocation / archival 生命周期）、**每个版本依次过 SHACL 图形状与策略校验、本体校验、咨询式 LLM 语义分析、人工复核，每层存机器可读证据**、**发布信封被 RFC 8785 JCS 与 RDFC-1.0 双重规范化后摘要并用分离签名签署**。而这周的实证就在旁边：同一天上榜的 `agy-fast`、`turbo-browser-mcp`、`agent-crop` 都是在别人的 Agent 里跑的第三方插件或 Skill——**一个 Skill 能读你的仓库、能改你的文件、能替你点提交，那么「这个 Skill 是什么版本、谁签的、依据什么」就从洁癖变成了安全问题。** **判断：Agent Skill 生态接下来会复制 npm 的全部历史，包括它的漏洞历史、投毒历史和 lockfile 需求——而现在还处在「Cargo install 一切」那个阶段。**
- **Agent 质量保证第一次被压进了 CI，而且单位经济学已经算得出来了**：`mobile-agent-testers` 的做法是**用 20 台模拟器上的 20 个 Claude Code Agent 当测试员**，按「设备 × 系统版本 × 语言 × 字号/缩放」这个人设矩阵跑探索性测试，交回带编号截图的 bug 报告，**每台手机的模型成本约 0.15–0.55 美元**。它和昨天出现的 `TwinFix`（**在一次性孪生环境里诊断、复现、修复故障的 Agent**）、`agent-crop`（**给 Agent 计时并做归因，把复盘写回指令/技能/工具**）构成了同一件事的三个面：**测（有没有坏）、复现（是不是真的坏）、归因（时间与成本去哪了）**。**判断：QA 这一行的成本结构是「人力 × 设备 × 回归矩阵」，而 Agent 把矩阵那一维的价格打到了几毛钱一台——被替代的不是「测试工程师」，而是「矩阵的组合爆炸」这件事本身；接下来真正稀缺的是「怎么判定一个 bug 报告是真的」这个判定器。**
- **Rust 重写完成了路线分叉：「整包重写」让位于「只改慢的那 5%」**：`rust-anything` 的路子是全量重写但每步都要过 `diff → gate`（Prettier 移植达成 19 倍加速、17,224 条录制用例逐字节一致）；而 `fast-anything` 明确反着来——**「不要用 Rust 重写它，把慢的那 5% 重写掉」**：先 profile 出真正吃时间的少数函数，让 Agent 只移植这些函数，**用真实录制的调用证明移植前后结果一致**再换进去，**一条命令、完全可回滚**，支持 13 种语言。**判断：这是「可验证重写」从炫技走向成本工程的第一步——对绝大多数企业代码库而言，先做性能剖面再决定移植范围，才是能被预算审批的方案；而把 rust-anything 那种「录制-回放」原语反过来用（只录热点路径），正是 fast-anything 的技术核心。**

- 为什么重要：**这条线把「Agent 落地的卡点」从模糊的「不够聪明」翻译成了两个可以分别结算的数字：每一步决策多少钱、每一步决策等多久。** 三个判断：其一，**Sys1 这个 9B 决策模型的定位才是真正值得注意的部分——它不做生成，只做分类**（选哪个工具 / 继续等 / 立刻执行 / 请求大模型），**这与昨天 Karpo Decision 31B 是同一条技术路线的两个不同落点**，一个 31B 追求决策准确率、一个 9B 追求把成本压到 1/27；**它们合起来说明「决策」正在从 System 2 的一部分变成一个独立的、可被单独采购的模型品类**；其二，**「适配还是 10 块」这句话点破了 Agent 落地的真实经济学**——**AI 把「开发一次」的成本从 90 压到 1，却没有动「每个客户重新认一遍业务流程、工具系统和现场设备」那 10 块**，而 MHS（硬件标准）与 Playbook（经验沉淀）正是冲着这 10 块去的：**前者让 Agent 不必为每个现场从零学协议，后者让上一个项目的踩坑变成下一个项目的起点**——**如果这条路径走通，它削掉的将是 Agent 交付行业里最贵、最不可规模化的那一段**；其三，**TTT × RSI 的「临时微调、干完恢复原样」是一个被低估的工程选择**——它避免了把每次现场经验都固化进模型参数（那需要重训、要评估、要防灾难性遗忘），**而是用「版本化 Playbook + 任务前临时适应」这两层轻量机制拿到八成收益**；**这对要上生产的 Agent 团队是关键区别——自进化如果不能回滚，就不能上生产线。**

### 6. [SpaceX 的 320 亿美元 AI 芯片债券：贷方要求这批芯片不得用于轨道数据中心，因为 300 英里高空的抵押品收不回来](https://techcrunch.com/2026/11/20/chips-can-survive-the-space-environment-can-their-financing/)

- 为什么重要：**这是「太空算力」这个叙事第一次撞上金融业的常识——而撞的方式非常具体：抵押品不能被收回。** 三个判断：其一，**债券市场对 AI 基础设施的定价逻辑是「资产可回收、现金流可预测」**，SpaceX 试图把抵押品放进轨道，等于**要求贷款人在资产完全不可变现的前提下承担当期信用风险**——**这不是技术问题，是信用结构问题，而信用结构比技术更慢、也更不可绕过**；其二，**SpaceX 与 Tesla 自建晶圆厂 Terafab 这个动作泄露了真实的战略意图**——**如果太空算力真的成立，那么「把芯片送上去」的成本最终要靠「自己造芯片」来摊薄**，而一个尚未动工、需要数年与数十亿美元的晶圆厂，说明这条路径的时间尺度远超当下的融资周期；其三，**地面路线反而在同步加固**——马斯克从火箭团队抽调工程师自行浇铸涡轮叶片、加速地面站建设，加上 Google 的 TPU 上天计划，**说明真正在跑的「太空数据中心」目前是「用地面算力把数据送上轨道再算」的变体，而非在轨道上架服务器**；**这对 2026 年的算力供需判断几乎没有影响，但对 2028 年之后的电力与选址格局有影响**。

## 🎯 AI 重点关注

- **AI 科研的瓶颈已经不在「能不能证出来」，而在「谁来担保它是对的」——而担保方式正在从同行评议转向机器验证，验收工序本身正在被封装成标准件**：本周出现了完整的一条链。正面一侧：**Lean 与 Mathlib 社区联合声明认证 Alpöge 的黎曼猜想证明（1,700 万行 Lean 代码，只依赖 Mathlib，Xena 四条准则全满足），MIT 的 Sutherland 用两个独立内核 nanoda 与 con-leche 复核并接受完整导出证明，复核流程本身由 Claude Code 驱动**；GitHub 上 **`leanprover-community/riemann-hypothesis` 当天冲到 626⭐，把提交镜像下来并配一套 `lake comparator` 独立复核**——**检查 Main.lean 恰好证明了那五条、只用 propext / Quot.sound / Classical.choice、且 Lean 内核与 nanoda 双内核都接受**；同日 `pequalnp.com` 把这件事群众化成「任何能跑 Lean 的 Agent 都能去啃一个开放问题，每个结果都必须过同一个检查器」。反面一侧：**Masullo 的 940 页人类 GRH 草稿 8 小时内被人用 AI 模型报告出问题**，而 Alpöge 自己的仓库也诚实列出**「数值证书尚未公开」**。**判断：这定义了 2027 年 AI 研究的准入门槛——「AI 提出了多少新结果」会迅速贬值，「有多少结果能被机器独立复核」会升值。** 对做工具的人有三条具体方向：其一，**投资应该压在「可读性与可复述性」上，而不是更强的搜索**——陶哲轩式的「答案无法直接从产物里读出来」是当前真正的瓶颈；其二，**验证器的易用性是新洼地**——`lake comparator` 需要两套 Lean 工具链才能校验 4.33.1 时代的提交，**这就是门槛**；其三，**「用 AI 找出 AI 产物的错误」正在成为一个独立工种**——Masullo 案例里的关键角色是「用不同 AI 模型辅助发现问题的数学家」，**这个角色会在明年大量出现在论文脚注里**。

- **「给 AI 限速」第一次有了技术指标，而指标选的是困惑度——但这条路线有一个结构性漏洞**：OpenAI 首席科学家 Pachocki 公开主张用困惑度作为衡量 AI 发展速度的通用标尺，首次公布 GPT-3.5（≈0.99）、GPT-4（≈0.91）到当前（<0.8）的下降曲线，并称 **低于 0.8 之后出现了网络安全与数学领域的变革性能力**；Altman 称之为「OpenAI 至今发表的最重要的东西之一」，Amodei 的「给前沿踩刹车」方案随之有了可量化抓手。**判断：这比任何政治协商都更可能成为事实上的行业标准，因为它是所有实验室都在暗中追踪、却从不对外公布的指标。** 但漏洞必须讲清楚：**困惑度是平均量，危险能力是尾量**——**一个模型完全可以把平均困惑度压低，同时在网络安全这类低频高危任务上保留极端能力**，所以真正的博弈会发生在「谁来定义这条线、谁来测量、谁被允许例外」上。**推论有三条**：其一，**「安全」正在从价值主张变成计量问题，而计量问题的解决路径是公开原始指标——这会削弱各家「我的模型更安全」的营销话术**；其二，**如果困惑度真被采纳为共同标尺，那么发布模型的节奏就会由「压低困惑度」这一单一指标驱动，而指标驱动会带来指标本身的投机**（在高频任务上优化、在低频高危任务上保留能力正是这种投机的自然形式）；其三，**对中国模型厂商而言这是一个必须认真对待的信号**——如果未来的安全协议长成「共同标尺 + 共同上限」的形状，**那么生态位最大的玩家有能力推动标尺的走向**。

- **AI 的能源账单和金融账单同时曝光，「AI 基础设施」正在从算力问题变成能源与信用的交叉问题**：能源侧，独立研究测算 **Anthropic 2028 年 87% 电力来自天然气、11% 来自煤，中位排放 3,200 万吨 CO₂e，其用电碳强度比美国电网均值高 35%，且 80% 自建电力用的是效率低下的简单循环机组**；**它在美国没有任何可再生能源承诺**，唯一公开的承诺与投资在挪威和加拿大，而它刚刚**买下 1.7GW 重型燃气轮机、金额 34 亿美元**。金融侧，**Anthropic 募资 1,048 亿美元，但未来 12 个月算力承诺就要付 707 亿、2030 年底前需 4,516 亿，总承诺 1.05–1.08 万亿美元**；**SpaceX 那笔 320 亿美元芯片融资的贷方直接要求芯片不得用于轨道数据中心，因为 300 英里高空的抵押品收不回来**。**判断：这两条线合起来说明同一件事——「AI 会继续增长」这个前提现在有了一个新的约束条件，而它不是模型能力，是电网与债市。** 接下来 12 个月最该盯的四个指标：**一、Anthropic 下一份 10-Q 里的算力承诺与资本开支口径**（对照已披露的 1.05–1.08 万亿）；**二、Anthropic 或同业披露的可再生能源采购比例**——目前美国的承诺数字是零，这个数字从零变成任何正数都会成为新闻；**三、云厂商「AI 收入增速 vs 折旧摊销增速」的剪刀差**（这是整条叙事最诚实的体温，因为它不依赖任何人对「泡沫」的定义）；**四、数据中心并网审批的碳强度条款**——当选址电网的碳强度比均值高 35%，**碳成本会第一次进入选址的财务模型，进而进入「AI 成本表」本身**。
