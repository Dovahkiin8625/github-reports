9. **hyperionaidev/smolmaxxing** ⭐ 299 · C

## 🔧 AI 技术栈 / 趋势分析

- **Agent 正在获得「工位、预算和上级」**：agentes-chat（1,188⭐）把 Agent 作为带 role / owner / budget 的成员放进 Slack 频道，在所有人可见的地方干活、敏感操作前先请示；lot-map（613⭐）则把 Claude Code 的每次工具调用、hook、skill 变成地图上的一束脉冲；AgentRun（604⭐）给每个 Agent 配一个「Learning 页」，记录这次留下了什么、下次变了什么。**Agent 的产品形态正在从「命令行里的一次调用」升级为「组织里的一等公民」——它开始有汇报线、有绩效、也有留痕。**
- **端侧推理被压到「1GB 内存跑 16B」**：smolmaxxing 在小米电视盒子上用 1-bit 内核 + flash 换页跑 16B MoE（5.1 tok/s）、在 2013 款 iPad Air 上跑 1-bit 1.7B（24–26 tok/s）；华为 MACaQ（210⭐，arXiv 2611.10649）声称 **64 分钟、32.5 GB 设备内存**即可量化 122B 模型，困惑度优于 MR-GPTQ 与 DuQuant++、达到 Llama-3-8B 水平所需量化时间少 11 倍；Veloresearch/kinetic（85⭐）用 Rust 重写 GGUF 推理内核并主打「任何加速都不会改变答案」的精确性；HN 当日 Edge0-145B 则把 145B 开源模型塞进笔记本（80+ tok/s、28GB 峰值内存）。**「本地跑得动」正在从极客爱好变成工程指标——省下的不只是 token 费，还有数据合规。**
- **Skill 从「提示词」变成「带验收的可执行交付物」**：ste80-humanizer（460⭐）把维基百科 26 条 AI 味特征清单 + Karpathy 的 STE80 受控英语合成一个 skill；nishant-Tiwari24/cracked（274⭐）打包 19 个 skill 覆盖 470+ 家公司的面试题与隐藏用例评分；threerocks/article2media（288⭐）把一篇文章或视频拆成 10 个可独立安装的 skill（抓取 / 视频转写 / 改写 / 翻译 / 长图 / 小红书卡片 / 公众号排版 / 口播视频 / 白板论证 / 漫画），**每种产出交付前自动验收，不合格直接报错**。**Skill 已经是不绑模型、不绑宿主、只绑 SKILL.md 加验收脚本的最小分发单位。**
- **多模态的战场从「像不像照片」转向「懂不懂几何」**：MiniMax H3-Image（304⭐）能从一张产品外观图推出标准正交三视图、画出符合装配逻辑的机械爆炸图并标注引线、还能生成排版零乱码的高数考卷并给出正确答案；op7418/guizang-game-skill（245⭐）把 Fable 5.2 花约 6 小时、4.5 亿 token 做出来的 3D 武侠动作游戏《雾锁山门》沉淀成 skill（含三段连招、闪避、格挡、处决、Boss 二阶段，原始素材近 100MB 打包成 33MB 单文件 HTML）；Moh4696/cinematic-skill（233⭐）干脆用 Skia 用代码逐帧画出带旁白、解说字幕与音效的纪录片，明确「不生成视频」。**垂直模型 + 代码渲染，正在绕开视频生成模型的天花板。**
