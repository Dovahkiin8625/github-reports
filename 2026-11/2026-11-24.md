## 🔧 AI 技术栈 / 趋势分析

- **Agent Skill 正在从提示词集合变成可安装的工程工具链**：今天候选池里 281 个仓库，光 `agent-skills` / `claude-code` topic 就贡献了上百个。它们共同的形态是「可执行的验证流程」——`inference-optimisation-skill` 强制交错对照并把失败一起记录，`antialgorithm` 强制模型先说出自己的平庸答案，`craft` 要求 Agent 先写设计简报再画界面。其中最典型的是同作者的 `rust-anything`（9,029⭐，要求整应用重写并**证明行为等价**）与 `fast-anything`（3,428⭐，要求只重写慢的 5%）——真正的新东西不在 Rust，而在**用录制回放做行为等价性证明**这套验证协议，Agent 从「写代码的人」被改造成「验收代码的裁判」。
- **国产开源进入「架构创新 + 参数规模」双线并进**：智谱 GLM-5.4 首次把 Loop Transformer 装进 750B 级旗舰（中间 28 层结果送回起点用同一套权重再算一遍），30B 对照实验显示训练算力只增约 10% 就把 AIME25 从 19.17 拉到 30.42、GPQA Diamond 从 47.58 拉到 56.26，同时平均输出 token 反降 11.7%；百度文心 5.5 Flash Preview 则以 Apache 2.0 开源 2800 亿总参/140 亿激活/百万上下文。**开源协议与架构改造同时成为竞争维度。**
- **Agent 的成本优化从「单步更便宜」转向「少走几步 + 少占配额」**：`agy-fast` 砍可计费配额 31%、`turbo-browser-mcp` 用一次调用干完一串事来减少回合，`antialgorithm` 从源头让模型少产出平庸答案。三条路径分别对应「省额度」「省回合」「省返工」，Agent 成本结构第一次被三个变量同时约束。
- **信任层是当前生态最明显的空白**：`signet` 用图谱优先 + 五层校验给 Agent 和 Skill 发「印玺」，`turbo-browser-mcp` 默认拦截所有提交类按钮，`agent-crop` 则把 Agent 的时间去向记成 JSONL 事件日志并把复盘写回指令/技能/工具。**Agent 开始需要「印玺」「缰绳」和「考勤」——这三样东西此前都属于人类组织。**
- **世界模型正从「视觉渲染」转向「物理仿真 + 音画同步」**：高德 ABot-World 0.5 在 WBench 基准拿到物理性与总分第一，支持自然语言实时重塑世界，README 显示单张 RTX 5090 就能跑 720P/16FPS/1.2s 延迟/19GB 显存的无限世界 rollout。蚂蚁则把多模态生理信号统一预训练（15 万小时）做疾病风险预测，两条路都在回答同一个问题——**模型能不能作为物理实验的载体而不只是内容的生成器**。

### 6. [OpenAI's chief scientist has thoughts on how to limit AI development](https://techcrunch.com/2026/11/22/openais-chief-scientist-has-thoughts-on-how-to-limit-ai-development/)
- 来源：TechCrunch | 时间：2026-11-22 17:25 PST
- 摘要：OpenAI 首席科学家 Jakub Pachocki 公开提出用 **perplexity（困惑度）作为衡量前沿模型能力的通用标尺**并以此限速——GPT-3.5 约 0.99、GPT-4 约 0.91、当前模型已低于 0.8，并称低于 0.8 后模型在网络安全与数学上出现变革性能力。Altman 称这是「OpenAI 至今最重要的发表之一」。HN 社区（micjm.com，同日发文）随即指出方法论漏洞：OpenAI 的困惑度曲线基于**模型预测一个固定的代码语料**，因此曲线下降可能只是反映了模型越来越多地训练在代码上；论文作者用 160M 模型做五组训练集对照（仅改变代码数据占比），在非代码文本上困惑度显著恶化——即训练语料里代码占 75% 的模型在代码任务上更强，但通用能力未必更强。

## 🎯 AI 重点关注

- **AI 叙事第一次被公开市场用单日涨幅定价，而不是用叙事周期** —— 黄仁勋 11 天辞任又复职，英伟达收涨 31.48%（创 2003 年 5 月以来最大单日涨幅）、单日市值增长 9,520 亿美元创历史纪录，纳指 +6.51%、标普 +4.73%、费城半导体指数 +14.03%，全部抹平上周的回调。**关键细节是 Anthropic 当日逆势下跌 1.43%**——AI 交易内部已经开始分化：算力叙事和模型叙事被拆开定价，「谁的 GPU 订单更多」从此比「谁的模型更强」更能决定股价。
- **国产开源的竞争焦点已经从参数量转向架构改造与协议选择** —— 智谱 GLM-5.4 用 Loop Transformer 在训练算力只增 10% 的条件下把 AIME25 提升 11.25 分、且输出 token 反而下降；百度文心 5.5 Flash Preview 直接以 Apache 2.0 开源 2800 亿参数。**前者是「用更少算力做更多事」，后者是「把大模型真正放进别人的推理框架」**——前者决定推理账单，后者决定生态渗透率，两条路不可互相替代。
- **Agent 生态的下一个战场是「交付链后半段」和「信任基础设施」** —— Claude Ship 把审批权交给 Agent、PR Steward 自动处理 CI 与合并冲突、`inference-optimisation-skill` 把推理调优变成可复用流程、`signet` 用五层校验给 Skill 发印玺、`turbo-browser-mcp` 默认拦住所有提交按钮。**过去一年大家在做「让 Agent 写代码」，现在在做「让 Agent 交付代码，并且能证明它交付的东西是对的」**——后者才是企业真正愿意放权的前提。
