## 🔧 AI 技术栈 / 趋势分析

- **「后训练供给」正在从「数据」升级为「环境」，而这是比 Scale Law 更难复制的护城河**：光轮智能在 CoRL 2026 发布 **RoboFinals RL Envs**，首发展示**超过 8 分钟的「汽车修理」长程仿真任务**——把灵巧手操作（十几到二十多个自由度 vs 平行夹爪的 1 个）、工具使用、多阶段流程与柔性体交互（软管、线缆、密封垫）耦合在同一条任务链里，且**前后阶段相互关联**（机器人必须承接前一步操作造成的状态变化，而非常见的「每段从人工设定的初始状态重来」）。其全栈自研仿真底座 SimFoundry 覆盖「求解—测量—生成」，其中生成环节由 **AI Agent 驱动**做资产重建与物理建模；Agent 化的校准工作流把最大位置偏差从初始仿真缩小约 **3 毫米**。背后的市场信号更硬：**Mercor 11 月 10 日完成 7.5 亿美元 D 轮、估值 200 亿美元**，运营 500 万人的专家网络；Surge AI 用 Qwen3.5-122B-A10B 做后训练，在从未见过的 SWE-Bench Pro 上提升 **5.7 个百分点**；Handshake AI 上线约一年，**年化收入已达 10 亿美元**。**结论：2026 下半年最被低估的生意不是模型，也不是算力，而是「让模型能练习的地方」。**
- **Qwen4-Max 把国产模型的竞争口径从「参数量」换成了「每任务的 Token 与成本」**：阿里 11 月 16 日发布 Qwen4-Max，**2.4T 总参数仅激活 71B**，采用全新 **Qwen 稀疏注意力（QSA）** MoE 架构，每 Token 激活参数较上代少 25%；在 Terminal-Bench 4.0 同一 Xhigh 思考档位下，**每次尝试平均 Token 用量从 289K 降至 151K（−近 50%）**，得分从 38.9 提升到 **48.5（+近 25%）**；按缓存命中价格计算，**完成单个任务的平均费用比 Qwen3.8-Max 降低 58%**，缓存命中价低至每百万 Tokens **0.5 元**。同时在 CodeArena 前端编程全球盲测排**第六**（居 GPT6-Astra 与 Claude Fable5.1 之间，刷新中国模型最好成绩）、Agents' Last Exam 拿 **46.7**（较上代 +18.8）、JobBench 68.5、HLAB-Vals-1.1 21.3。更值得注意的是它已经在真实产业里跑：汽车制造场景把单个工件加工编程人工用时从 **475 分钟降到 24 分钟（−95%）**，金融投研场景熟练调用 **90 个 MCP 工具**产出 Excel 底稿与 PPT 报告并支持双重溯源，材料发现连续自主运行 **48 小时**从 270 万个候选分子中筛出候选并真实合成出一种新型冷却液。**英伟达正在被围攻的「每美元 Token 产出」这条阵线，国产模型已经带着成本曲线走进来。**
- **Agent 的「可见性」和「凭证边界」正在成为一类独立的基础设施产品**：今天的三条证据指向同一件事——lot-map 把 Claude Code 的工具调用画成实时地图并配隐私与原则文档；**OpenCode Browse** 让 Agent 使用你的真实浏览器，**但把登录与 2FA 交还给你**（Agent 读、点、输入、截图、录制标签页，人来接手认证）；lend 让跑在远端 VM 上的 Agent 用你笔记本上的工具，**但不经手你的 SSH key 与 1Password 保险库**，而是每次调用都回来求批准；yogurt 则把「本地 MCP server」做成只读授权。**这个方向的共同点是：能力在扩张，但「谁能碰到真凭证」必须由基础设施而非提示词来保证——而这正是加州总检察长起诉 OpenAI、Artex 开源黑客工具被 FBI 通报之后，整个行业被迫补上的那一课。**
- **Agent 已经进入「负责任披露」阶段，而工具本身变成了攻击面**：FBI 11 月 16 日的闪速告警确认，开源 AI 黑客工具 **ARTEX** 自 7 月公开以来被用于多起攻击——**部分攻击「不到三小时」就从探测推进到完全沦陷**，攻击面覆盖金融、政府、科技、国防、通信与互联网行业；已确认攻破**韩国多家金融机构**（导致至少 **6.8 万人**个人信息被盗）、美国 IT 管理巨头 **ConnectWise**（至少 **2,250 家**客户的 Microsoft 365 环境被访问，微软称攻击者「很可能是中国人」），Barracuda 也披露被同一波攻击波及。同日 artex 上游的 Docker 镜像被发现含未认证命令执行后门，社区随即用源码重编译出干净发行版。而另一个更日常的版本是 **Windows 11 在收集你用了哪些 Coding Agent**：逆向发现 `MissionControlAggregator.dll` 里嵌了 `copilot.exe`、`claude.exe`、`codex.exe`、`agy.exe` 四个 CLI Agent 槽位与 `github.exe`、`cursor.exe`、`antigravity.exe` 等桌面 Agent 槽位，功能开关名为 `CLICodingAgentUsage`（feature ID 62580080），把使用痕迹写进本地并上报 Windows Diagnostics。**「谁在监视我们的 Agent」和「我们的 Agent 在替谁干活」已经是同一个问题。**
- **物理 AI 的训练瓶颈从「算法」挪到了「环境可判定性」**：光轮提出的 **RL Ready** 标准把要求讲得很直白——任务语义上每个阶段要有明确完成判定，物理交互上试错条件下的反馈要可靠，反馈信号要能直接用于训练。OpenAI 的 **GPT-6 Astra** 是这条线的验证点：在 RoboDojo 的 42 个仿真任务上**不做任何机器人专项微调**，平均成功率 **22.48%**，超过榜单上全部 40 个经过训练的机器人策略，投资人称其为「机器人领域的 GPT-3 时刻」；但真机测试暴露短板——方块入碗 20 次成功 19 次，精密插销任务 20 次只成功 2 次。**结论很直接：物理 AI 的「通用模型时刻」已经到来，但瓶颈从「模型会不会」转移到了「环境能不能教会它」，而环境的建设速度现在决定着机器人商业化的速度。**

- 摘要：美国商务部发布临时最终规则（IFR），**凡可能向中国等受限国家提供算力服务的公司，均需申请出口许可**。规则针对美国 D:5 禁运国集团（**包括中国、俄罗斯、伊朗、朝鲜及其他 18 国**），覆盖数据中心或任何能提供 **超过 1,200 万 TPP**（约等于 750 张 H100/H200 的最大算力）的网络与间接访问路径；**存量数据中心运营商须在规则生效后 90 天内取得许可**。同时新增对 **马来西亚、新加坡、印尼、泰国、巴西** 芯片出口/再出口/转让的许可要求（商务部称这些国家「转移风险高于常态」），但对最终目的地为美国企业的芯片豁免。规则明确豁免商业推荐系统（如电商与社交媒体使用的那类）。规则原文称「这将削弱受关注国家总部企业使用美国先进超级智能（SI）半导体训练先进 SI 模型的能力」。值得注意的是，此举紧随英伟达联合创始人黄仁勋辞职——**美国政府一直在试图把 Megaspeed 列入实体清单，因其据称采购数千张英伟达芯片转供中国算力业务以绕开出口限制。**
