## 🔧 AI 技术栈 / 趋势分析

- **Agent 从"个人 Skill 集合"走向"公司化组织"**：headcount 把 Claude Code 组织成 15+ 部门 / 125+ Skill 的可独立安装矩阵，sepia 跨 77+ Agent Skills CLI 客户端做"反 AI 写作"，说明 Agent 生态的分发单元已经从 Prompt → Skill → **Team / Org** 三级跳跃。
- **国产 Embedding / 多模态表征在开源榜罕见登顶**：Tencent/WeMM-Embedding（5 天 1,005 ⭐）由微信视觉团队开源，对标的是 OpenAI CLIP / Cohere Embed v3。国产在 Embedding 层公开可用的旗舰模型仍稀缺，这是一次明确的"补位"信号。
- **Planner + Executor 双脑分工成为 Agent 工程主流**：codex-with-chatgpt 把"思考"交给 ChatGPT、"执行"留给 Codex Harness，本质是 Anthropic / OpenAI 都认可的"模型层 vs Harness 层"分离架构——未来 Agent 框架的核心争论点将是 **"谁的 Planner + 谁的 Harness"**。
- **Token 经济学工具开始有产品形态**：tokentab 把"按模型 / 项目 / 日"算 token 账单做成 CLI，呼应亚马逊 180 万美元烧 Claude 这类真实痛点。**Agent 时代的 FinOps / Cost Observability** 正在变成一个独立赛道。
- **多模型 Studio 把"模型即 UI 单元"做出来**：open-higgsfield 把 Sora / Veo / 可灵 等多视频生成模型放在一个 prompt bar 里——说明前端不再为某个模型写死参数，每个模型都以"插件单元"形式被消费。
