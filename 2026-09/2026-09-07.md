## 🔧 AI 技术栈 / 趋势分析

- **Agent 正从“聊天入口”转向业务流程编排**：commerce-agents 同时覆盖零售、通信和娱乐，short-video-generator-AI 则把检测、字幕、翻译、配音串成流水线。竞争焦点已经从单轮回答转向工具调用、状态管理和结果交付。
- **可验证性成为 Agent 的第二条主链**：reverify 用确定性工具检查模型结论，Fermat 项目使用 Lean 形式化证明；在代码、金融和科学场景，谁能提供证据链，谁才更接近生产级部署。
- **个人数据正在变成 Agent 的本地上下文层**：wechat-intelligence-hub 选择 local-first 和只读 CLI，既能搜索历史又能生成跟进事项，折射出用户对云端全量读取的隐私担忧与对个人 Agent 的真实需求。
- **AI 开发成本开始被产品化管理**：codenotch 同时追踪 Claude Code、Cursor、Codex 和 Antigravity 用量，说明模型调用额度、上下文窗口和订阅组合已经从“后台参数”变成开发者可见的运营指标。
- **模型能力正在进入物理世界与硬件栈**：机器人在线强化学习、神经渲染、智能眼镜和国产异构算力同时出现，下一轮差异化不会只由 benchmark 决定，还要看延迟、能耗、设备适配和持续运行能力。

## 🎯 AI 重点关注

- **下一阶段的 Agent 竞争是“上下文 + 执行闭环”**：commerce-agents、wechat-intelligence-hub 和 SmoothRL 分别代表业务流程、个人数据与机器人控制三个方向，模型本身只是中间件，真正的壁垒在状态、工具和反馈环。
- **科学 AI 正进入“生成—证明—复现”阶段**：GPT-6 数学争议与 Claude/Lean 形式化证明形成鲜明对照；不能提供可检查证据的模型突破，商业价值和科研可信度都会打折。
- **安全治理必须跟上 Agent 权限扩张**：不受限图像服务、OpenAI wiki incident 和“rogue agent”类报道共同说明，模型一旦能访问外部系统，审计、最小权限和公开披露就不再是附加功能。
