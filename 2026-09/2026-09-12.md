- **Agent Skills（SKILL.md）已成本月事实标准**：今日 Top 10 中 holo-card-studio、codex-astra-luna-orchestrator、anything2explainer、dream-loop、handraw-style、screenwriting-skills 全是 Skill 模板——继 8 月「claude-red / human-writing」之后，9 月第二周 Skill 化全面占领榜单，"SKILL.md = Agent 时代的微应用"路径被再次验证。

- **AI for Math 进入「形式化证书」时代**：OpenAI 同日放 NavierStokesAndEuler 的 Lean 证书 + GPT-6「循环 Transformer」刷屏 + 陶哲轩吐槽「孪生素数」突破——数学界与 LLM 界的边界争议，已经从"能不能"走到"能不能被机器验证"。
- **端侧 / 边栏 Agent 体验成型**：vinzdg/codenotch 把 Agent 用量监控做成 macOS 边栏工具、Gemma 端侧翻译、phone-harness 等延续"Agent = 数字员工"叙事，开发者开始用"操作系统级 UI"去观察 Agent——这才是 Agent 商业化真正的体验拼图。
