## 🔧 AI 技术栈 / 趋势分析

- **国产 LLM 走出"模型 + Harness"双轮路线**：月之暗面 Kimi K3 通过 Harness 逼近 Opus 5（量子位报道）+ DeepSeek V4 推出 J-Space 能力兑现评估，国产团队不再只拼模型本身，而是把 Harness / 插件协议 / 能力评估打包成新的竞争面——这是 Anthropic、OpenAI 暂时没有正面卷的赛道。
- **MCP 正在成为"代理协议层"事实标准**：OpenBot、northcinder、sprix-sage-router、CopilotKit 一众上榜项目全部以 MCP / AG-UI / A2A 为接口约定。2026 下半年的 Agent 生态已经默认"先 MCP、再业务"，没有 MCP 支持的工具基本进不了新项目。
- **DSH（DeepSeek Harness）生态一周内冲进 Trending Top 15 的 5 个坑位**：dsh-routing-suite（6.4K⭐）、dsh-anchored-standard（3.7K⭐）、dsh-market、dsh orange-book、桌面客户端 EAC。"Harness 即插件市场 + 桌面 + 路由 + 评估"的闭环已跑通，下一步看点是能否被海外开发者接受。
- **Agent Skills 化进入"图像 / 品牌 / 增长黑客"纵深**：ip-as-logo-skill 上榜、之前已有 human-writing、open-kimi-ppt-skill、awesome-growth-hacking-skills——SKILL.md 正在变成"AI 应用的最轻量分发单元"，比写完整 App 的门槛低一个量级。
- **"AI 来源水印清除"工具化是治理短板信号**：watermarks-remover 直接打 Claude / Codex / Grok-45 的水印体系——C2PA、Unicode、统计水印全部可被脚本级擦除，行业必须在水印 / 检测 / 立法侧同步加码。
