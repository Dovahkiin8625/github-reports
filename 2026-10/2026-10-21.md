- **推理成本战从「模型定价」下沉到「集群调度」**：DeepSeek 官方下场开源 DeepInfer（12.7K⭐ / HN 2,135 分），同日是石科技在 CCF 高性能计算大会发布 TokenFleet 分布式调度框架，拿「首 Token 延迟降低 32.4%」当卖点。三项核心技术（TokenPilot 选点 / FleetMind 跨机房协同 / SLOMax 混合负载治理）全部围绕「有效 Token 产出」而非单卡性能——说明推理竞争已经从卡标转移到调度算法。

- **端侧 AI 从 Demo 变成可下载产品**：cleanyourtv 与 free-my-tv 两个 Google TV 项目同日上榜、合计近 1.4 万星，且都明示由 Claude Code / vibe coding 生成。Android TV 长期缺乏优质开源桌面，这是典型的「模型能力溢出到消费级固件」的机会窗口。
