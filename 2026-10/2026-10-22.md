## 🔧 AI 技术栈 / 趋势分析

- **Token 经济学压过模型榜单**：headroomlabs-ai/headroom（7.7 万星，主打 JSON 省 60-95% token）与同日光位 MiniMax M3.1 Flash（输入 1 元 / 百万 token、输出 4 元、综合成本压到上代 30%）指向同一件事——2026 下半年的竞争单位不是"最强模型"，而是"每美元能完成多少 Agent 任务"。
- **Agent 记忆成为独立基础设施层**：akitaonrails/ai-memory 用 Rust 做跨厂商 Agent 长期记忆，量子位同日《RSI 三块关键拼图，MemT 1.0 从模型层补上「记忆」》也在讲同一件事——自进化系统的瓶颈已从"会不会想"变成"记不记得住"。
- **知识图谱 vs 向量库路线之争出现分叉**：Graphify-Labs/graphify（13 万星）坚持本地确定性 AST 解析 + 每条边可解释 + 不用向量库，这是对 RAG"黑箱检索"的一次正面反驳；而 headroom 则选择把向量检索结果先压缩再喂给模型。
- **Agent 编排与治理分层成型**：stablyai/orca（10 万星）做多 Agent 舰队调度，cloudflare/security-audit-skill（3.6 万星）做可机器验证的安全审计——一个管"跑多少个 Agent"，一个管"Agent 的结论能不能信"。
- **国产阵营的三条并进线**：MiniMax M3.1 Flash 以 30% 成本拿下 Agents Last Exam 国模第一（29.6%）；清华系千诀科技发布预测式世界模型 Polibrain（隐变量可辨识性研究早 LeCun 团队约一年，已适配四足/人形/轮式/双臂）；清华 AIR 孵化的紫荆智康把多学科 AI 分身协作推进到真实医院。价格、世界模型、垂直场景，国产同时在三个维度施压。

- 摘要：LiteLLM 1.107.0 在 PyPI 上被植入 `.pth` 形式的凭证窃取器与 `sitecustomize.py` 后门，**每次 Python 启动都会执行**。LiteLLM 是各大厂 LLM 网关的事实标准之一，泄露面直接覆盖企业持有的全部模型 API Key。
