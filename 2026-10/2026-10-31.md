## 🔧 AI 技术栈 / 趋势分析

- **Skill 已经从「提示词文件」变成有分发、有版本、有供应链风险的软件包**：官方 anthropics/skills 已经 18.5 万星，mattpocock/skills 30.7 万、obra/superpowers 30.9 万同一天挤进日榜，expo/skills 和 android/skills 也各占一席，unclebob/ub-mode、tstack、unslop 全是同一种货色——把方法论打包成可安装的 skill 包。而 Phorion 在同一天披露，Cursor Marketplace 上分发的**官方** Claude Code for VS Code 扩展 bundle 里藏了跨 macOS / Linux / Windows 的持久 SSH 后门，HN 拿 779 分、489 条评论。skill 是代码，代码要进 CI 审计，不能等出事再补。

- **端侧 Agent 的评判标准已经从「模型多强」换成「能不能在真实设备上把事办完」**：今天的 base 15 里端侧占了三席——dsh-Go 内置 Linux 免 Root 免 Termux 在手机上跑 harness 并能遥控电脑，Mika 在后台隐藏屏上操作 App 和网页，digital-human-koubo 一张照片一句话产出 27 秒成品口播。共同点是把「能演示」和「能交付」之间的最后一公里工程化：安装路径可被另一个 Agent 自动执行、密钥不经过中间人、涉及付款与验证码的动作一律交还用户。

- **国产算力第一次拿出了可以逐项对标的硬数据**：天数智芯天垓300 云端 PK 同一任务用时 95.6 秒 vs H200 的 112 秒；PD 分离部署下单卡端到端吞吐是 H200 的 1.05 倍，GLM-5.3 在 64K 规模下 MoE 吞吐 1.15 倍 H200、8K→128K 长上下文 Agent 首字延迟低 10%~30%，Qwen3-32B 的 8 卡 FP8 训练每卡有效吞吐是 H100 的 1.33 倍，满负荷步时波动 0.43%（Hopper 方案 0.76%）。IXL144 超节点把 144 颗 GPU 塞进一个标准机柜、聚合显存约 10.1TB，每百万有效 token 成本较 H200 方案降约 40%；国内首个 GPU+XPU 异构 AFD 分离方案让 Decoding 推理延迟降低 60%。端侧彤央 TY1200 标称 300 TOPS 稠密算力（Thor T5000 官方 2070 TFLOPS 且是 FP4 稀疏），跑 Qwen3.8-27B 达到 Thor 的 138%、Cosmos-R2-8B 达到 180%。

- **AI 正在接管最贵的那层手写代码，而这件事在国产芯片上更值钱**：面壁智能 ForgeKernel 在 B200 上 42 轮迭代、32 个版本、1 张卡 22 个 GPU 小时，写出 472 微秒的 FlashMLA Prefill 算子，比 DeepSeek 的 518 微秒快 9.8%，全程人类代码 0 行；29 项对比中 24 项打平或超越专家实现，三套领先 Agent 系统公开的 7 个最强算子也全部打平或超越。同一套方法登顶昇腾 CANNBench 950DT（4010.75 分、领先第二名 27.8%）、950PR（4165.94，加速比 1.638×）、A3（4341.16，加速比 1.898×）三大硬件榜——从 B200 迁到昇腾只需把性能分析工具从 NCU 换成 msprof。团队自己算过一笔账：同样的做法在国产芯片上提速 20%~30%，在英伟达上只有 5%~10%。CUDA 生态十几年攒下来的专家经验，正在被 Agent 摊平。

- **资本开始按「能不能自己还钱」给 AI 重新定价，而开源阵营在同一天补位**：Anthropic 表外远期履约义务近 9000 亿美元，其中表外采购协议从去年 12 月到今年 6 月翻至四倍达 2656 亿、最长签到 20 年；四大科技巨头今年 capex 超 7400 亿美元，微软、谷歌、亚马逊、Meta、甲骨文合计发债额是去年的三倍，而 Alphabet 连续两个季度自由现金流为负、Amazon 过去 12 个月自由现金流 -424 亿。另一头，Mistral 开源万亿参数 Mistral Large 4，官方称性能对标 GLM-5.3 但每任务少用 47% token，蚂蚁百灵开源 Ling-3.1-flash-1019 智能指数 44 分、8 领域 47 项 benchmark 中 32 项胜过 DeepSeek-V4-Pro-Base 与 MiMo-V2.5-Pro-Base，英伟达还基于 MiniMax H3 开源了可自部署的 4K 视频重生成（UniPercept 60.0 vs 官方 API 53.4）。两条路线的合流点是同一个词：把一次任务的账单压下去。

## 🎯 AI 重点关注

- **Anthropic 的 9000 亿是这个行业的定价锚**：807 亿净亏损里 720 亿是可转债等金融工具的会计估值变动，不是现金流出——但 9000 亿远期履约义务是硬的，其中表外采购协议半年翻四倍到 2656 亿、最长签到 20 年。它若真如 Blackstone 所料拿到「high junk」评级，那么后续每一家前沿模型公司的算力融资成本都会被市场按这条曲线重新定标。今天 GitHub 上 Mistral Large 4（每任务省 47% token）、OXR（1.3B 跑完 100 页文档解析只要 101 秒）、天垓300（每百万有效 token 成本降约 40%）、Ling-3.1-flash-1019（47 项 benchmark 中 32 项超 DeepSeek-V4-Pro-Base）同时冲榜，不是巧合——当上游融资成本上升时，开发者会同时去找「自己便宜 10 倍」的模型和「自己跑不花钱」的方案。

- **国产算力的瓶颈已经从硬件转移到软件，而软件这一层正在被 Agent 填平**：天垓300 在随机出题、现场计时的 PK 里跑出 95.6 秒 vs H200 的 112 秒，硬件侧的故事已经能讲了；真正的短板是 CUDA 里十几年攒下来的算子优化经验。ForgeKernel 用同一套 Agent 系统在 B200 和昇腾三榜同时拿第一、从 B200 迁到昇腾只需换一个性能分析工具，正好击中这个痛点。官方路线图写得很清楚：超越 Hopper 只是第一站，接下来是 Blackwell、Rubin——当硬件代差还在原地，软件杠杆就成了唯一能立刻兑现的差距。

- **Skill 和 Agent 扩展已经是和 npm 同级的攻击面，必须进 CI**：anthropics/skills 18.5 万星、mattpocock/skills 30.7 万、obra/superpowers 30.9 万——skill 已经是一个有分发渠道、有版本管理的软件生态，而不是配置片段。同一天 Phorion 披露官方 Claude Code for VS Code 扩展在 Cursor Marketplace 上被植入跨 macOS/Linux/Windows 的持久 SSH 后门，HN 779 分。企业该做的不是发通知，是把 skill 扫描写进流水线（NVIDIA 的 SkillSpector 已可直接用），并且默认「安装即执行」这个动作需要像 npm 包一样过一遍审计。
