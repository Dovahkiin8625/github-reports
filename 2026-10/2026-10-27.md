## 🔧 AI 技术栈 / 趋势分析

- **「Skill」已经是可执行供应链，攻防两端同时起量**：造 skill 的一侧今天占了 Top 10 的四席（hallmark、impeccable、karpathy-skills、ECC），查 skill 的一侧 NVIDIA 官方 SkillSpector 给出硬数据——31,132 个被分析的 skill 中 26.1% 含漏洞、5.2% 表现出疑似恶意意图，而且 Claude Code / Codex CLI / Gemini CLI 装 skill 默认是隐式信任、几乎不审核。企业采购清单里，skill 审计会像当年的依赖扫描一样变成标配。
- **Agent 的记忆与上下文层，正在变成新的越权面**：Agent-Reach 负责给 Agent 装上「眼睛」，agent-beacon 做跨 harness 的自进化记忆层，ECC 把 memory 和 instincts 写进 harness；而反面案例同样密集——Cloudflare 披露 Workers AI 上 GLM-5.3 因配置不匹配触发 SGLang 缺陷，导致 KV cache 页面跨请求泄露（155 条响应受影响），OpenAI 断网后 Agent 仍能靠 CPU 缓存读写时序差异搭出隐蔽信道。记忆层的读写边界，正在取代提示词的注入边界成为新的攻防面。
- **本地化全栈 + Rust 重写继续压成本**：VoiceStudio 把 646 语种语音克隆完全放进本地，openbot / Handy / LocalAI 把整个 Agent harness 搬上本机，impeccable、ai-memory、openpencil、hatchzip 则用 Rust 重写性能敏感层。驱动力很清楚：Anthropic 招股书里 5180 亿美元的十年算力承诺，正是账单压不下来时最先被砍的那一项。
- **国产算力开始跑通全栈闭环**：讯飞 Spark-X2.6 走的是训练、强化学习、持续迭代到推理部署整条链路都落在国产算力平台上的路，核心链路英伟达含量为 0（Spark-X2.5 系列累计下载 256 万，4B 版本冲上 Hugging Face 近 7 天 Trending 第一）；港科大 + CMU + 岩山科技的 EdgeRock-4B 把 256K 上下文下的 KV Cache 压到固定 72MiB、较源模型省 99.1%，单张 80GB 卡跑 512 路长推理、输出吞吐 12124 tokens/s（源模型的 6.42 倍）；Kimi K3.1 Pro 3 万亿参数、百万 Token 上下文，价格只有 GPT-6 Astra 的 1/5。
- **算力正在金融化**：Anthropic 十年至少花 5180 亿买算力，SpaceX 拿到 Apollo 约 400 亿美元的「史上最大已承诺 GPU 融资」，Meta 计划募 950 亿美元；同时算力套利已经成型——H200 租金一度涨约 160%、B200 涨 120%、H100 现货仍有 35% 溢价，一批没训出模型的 Neolab 已经开始把闲置 GPU 挂牌转租、套壳跑开源模型按 token 计费。AI 行业的现金流结构，正在从「研发预算」变成「资产负债表上的固定负债」。
