## 🔧 AI 技术栈 / 趋势分析

- **Skill / Plugin 正在取代 MCP 服务器成为 Agent 的分发单元**：这周 GitHub 周榜 15 个仓库里，至少 6 个是 skill 形态——cloudflare/security-audit-skill（+12,680）、anthropics/claude-plugins-official（44,371）、anthropics/knowledge-work-plugins（32,660）、cursor/plugins（13,920）、android/skills（9,603）、aws/agent-toolkit-for-aws（3,151）。交付物不再是"一个要部署的服务"，而是"一份提示词 + 一条现成命令"，安装门槛从分钟级降到秒级，代价是分发权回到了 marketplace 手里。
- **Rust 正在重写 Agent 的运行时层**：NVIDIA/OpenShell 用内核插桩 + 形式化验证来做权限边界，pbakaus/impeccable 把 62 条检测规则做成 CLI，akitaonrails/ai-memory（本周 +3,541）用 Rust 实现跨 Agent 的长期记忆交接——凡是要进内核、进文件系统、进长期状态的环节，C/C++/Rust 正在系统性地把 Python 生态挤出去。
- **"让所有软件对 Agent 可用"成了独立赛道**：HKUDS/CLI-Anything 生成 CLI 适配层 + 社区 CLI-Hub、morluto/rea 用一个 MCP 覆盖二进制/应用/运行时三层、Colby McHenry 的 codegraph（75,225 星）预索引代码知识图谱并随代码变更自动同步——同一件事的三种解法：不是让 Agent 学新工具，而是让工具主动变成 Agent 友好的形态。
- **能力正在从云端往"端侧 + 物理"两端跑**：Block 的 Dessa 全双工语音模型能在 M4 Max 本地跑，microduck 把 25 cm 双足机器人的策略用 RL 训出来，hyperframes 让 Agent 用 HTML 直接产出 MP4——共同点是推理不再发生在机房里的 GPU 上，而是发生在耳机、桌面和地板上。
- **安全边界第一次跑到了模型能力前面**：Cloudflare 官方审计 skill 的六阶段里，"给每个候选漏洞配一个全新的验证 Agent 试图证伪"是关键设计；NVIDIA 干脆用内核级强制 + 形式化验证来管 Agent 权限；同期 HN 上 Node2Shell 演化成 HTTP2Shell、Google Brotli 解码器 CVE-2026-111497 影响 requests/httpx/aiohttp 等几乎所有 Python HTTP 客户端。当"一个 Agent 能读写文件、调 API、用凭证"成为默认配置，隔离层就不可能再是后补的补丁。
