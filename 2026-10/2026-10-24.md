## 🔧 AI 技术栈 / 趋势分析

- **Agent Skill 正在把 MCP 的成本打穿**：leanrea 用 8 KB 的 SKILL.md 替掉 REA 的 25 MB npm 包 + MCP 服务器 + 207 个工具定义，"回一句 OK"的上下文成本从 400.7k tokens（$1.60）压到 34.5k tokens（$0.09）；OpenAI 官方的 `php2shell-checker` 同样只交付两个 SKILL.md。分发单元正在从"MCP 服务器"退回"一份提示词 + 一段现成命令"，这会直接改写 Agent 框架的上下文预算模型。
- **"AI 写的消费电子工具"正在屠榜**：15 个仓库里 5 个是 Android TV 桌面 / 去广告，且 cleanyourtv、free-my-tv 都挂着 `claude-code` 标签，tv-detox 直接把"让 Claude Code 或 Codex 清理我的电视"做成了可安装产品。vibe coding 正从"写个 demo"下沉到"改造真实硬件"，电视盒子意外成了 Agent 第一个规模化消费场景。
- **同一个 CVE 养活三个仓库，AI 同时是发现方和放大器**：ikow 的 PoC（5 条 RCE 链 + 三套检测规则）、9bie 的免配置绕过、OpenAI 官方的版本检查器同日上榜，对应 TechCrunch 报道的 NSA 紧急预警——PHP 驱动着全球约 70% 的网站。AI 让漏洞从"被披露"变成"被规模化复现"，防守方只能把版本核查也做成 Agent Skill 才追得上。
- **世界模型从"逐帧生成"转向"状态变量"**：达瓦科技 Scenes AI 把场景、人物、相机、灯光、物理拆成可单独读写的变量，改一处只重写受影响的部分，单张 RTX 显卡跑实时世界模型并拿下 NVIDIA 创业企业展示卓越企业奖；Hacker News 上 613 分的 WorldTUI 则把一个 360M 模型微调成"假终端"——没有 shell 没有文件系统，模型只预测按键后屏幕怎么变。两条路线都在把预测目标从"下一帧长什么样"换成"下一个状态是什么"。
- **Agent 开始接管物理接口**：3d-model-anything 用 iPhone LiDAR 采集 + skill 引导 Agent 建模，huashu-motion 让 Agent 自己写谱配乐产出 53 秒成片并支持指哪改哪。Agent 的能力边界正从"改代码"扩展到"操作传感器、交付可交付物料"，这比再发一个模型更接近真实生产力。
